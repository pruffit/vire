# Безопасность

## Куда сообщать об уязвимости

Не открывайте публичный issue. Напишите на **kotlaevdanilcontact@gmail.com** с темой
`security: <короткое описание>`. Ответ — в течение 72 часов.

Полезно приложить: затронутый эндпоинт или экран, шаги воспроизведения, версию
(тег `vX.Y.Z` или коммит), оценку последствий.

## Что в периметре

- `viremusic.ru` и `cdn.viremusic.ru`
- API `/api/v1/**`
- клиенты: веб, Android (`com.virespace.viremusic`), десктоп (Tauri)

Вне периметра: отчёты сканеров без подтверждённого воздействия, отсутствие
заголовков без вектора эксплуатации, социальная инженерия, DoS-нагрузка на прод.

## Что уже описано

Модель угроз и покрытие — `docs/security/owasp-top-10.md`. Права и роли —
`docs/features/rbac.md`. Аутентификация устройств — `docs/features/device-auth.md`.

Известные осознанные размены (например, rate limiting fail-open при недоступности
Redis) зафиксированы там же — если находка совпадает с уже описанным решением,
напишите всё равно: возможно, размен пора пересмотреть.

## Зависимости

`pnpm audit --audit-level=high` — гейт CI, блокирует релиз. Advisory без патча в
апстриме проходят с `--ignore-unfixable` и разбираются вручную.
