# Иконки

Сюда складываются исходные SVG-паки. Раскладка по назначению:

- `social/` — соцсети (VK, Telegram, Instagram, YouTube, TikTok, X, …)
- `streaming/` — стриминги и магазины (Spotify, Apple Music, Яндекс Музыка, Deezer, …)
- `system/` — общий UI-пак для единообразия иконок по всей системе
  (стрелки, навигация, действия, статусы и т.п.)

## Соглашения (чтобы иконки были единообразными)

- Имена файлов — `kebab-case.svg` (`apple-music.svg`, `chevron-right.svg`).
- По возможности монохром: `fill="currentColor"` / `stroke="currentColor"`,
  без жёстко зашитых цветов — тогда иконка подхватывает цвет текста и тему.
- Квадратный `viewBox` (обычно `0 0 24 24`), без лишних `width`/`height` на корне.
- Убирать метаданные редактора (комментарии Figma/Illustrator, `<title>` по желанию).

Бренд-иконки площадок (social/streaming) могут быть цветными — для них единообразие
не обязательно, важна узнаваемость.
