# Product

## Register

product

## Users

**Артисты** — независимые музыканты СНГ, создающие и продающие музыку напрямую. Работают в дашборде: загружают треки, управляют релизами, настраивают персональную страницу. Ценят простоту и скорость, не хотят бороться с интерфейсом.

**Слушатели** — ценители независимой музыки. Открывают новых артистов, слушают, покупают FLAC, подписываются на любимых. Основной путь: главная → артист → релиз → трек.

## Product Purpose

Независимая музыкальная площадка для рынка СНГ: прямая связь артиста и слушателя без посредников. Артист получает полный контроль над страницей, ценообразованием и данными. Слушатель получает музыку в высоком качестве с личной историей покупок. Успех = артист опубликовал релиз и продал FLAC-копию без трений.

## Brand Personality

**Точный. Живой. Свой.**

Инструмент с характером: не безликий стриминг и не перегруженный лендинг. Ближе к качественному аудиооборудованию, чем к SaaS-продукту. Тёплый, но не китчевый. Серьёзный, но не холодный. Движется как живой организм — всё взаимодействие имеет физический отклик.

## Anti-references

- Spotify / Apple Music (generic streaming cliché)
- Bandcamp (устаревший UI, нет характера)
- SoundCloud (перегруженность, рекламный шум)
- Любой «музыкальный стартап» с purple-to-blue градиентом, glassmorphism и hero-metric template
- Безликий shadcn-дефолт без кастомизации

## Design Principles

1. **Инструмент, не витрина.** Интерфейс должен исчезать в задаче — не украшать, а давать контроль. Каждый экран отвечает на вопрос «что сейчас делает пользователь», а не «как выглядит продукт».

2. **Физический отклик.** Всё интерактивное должно ощущаться нажатым, потянутым, сдвинутым. Spring-физика везде, optimistic UI по умолчанию. Пользователь чувствует контакт с данными, не ждёт сервера.

3. **Пространственная логика.** Элементы приходят откуда-то и уходят куда-то. Shared-element переходы, expand из точки клика, drag-dismiss — контент имеет физическое место в интерфейсе.

4. **Характер через детали.** TE-эстетика: monospace для данных (BPM, длительность, вес файла), засечки на приборах, утилитарная плотность там где нужна плотность. Не декор — информация.

5. **Тёплая тёмная платформа.** Нейтраль с лёгкой подкраской (hue ~75), не pure gray. OKLCH-токены. Страницы артиста темизируются через CSS-переменные поверх платформенной оболочки.

## Accessibility & Inclusion

- WCAG AA (минимум) для публичных страниц
- `prefers-reduced-motion`: все анимации имеют мгновенный fallback (0.01ms)
- `:focus-visible` на всех интерактивных элементах
- Клавиатурная навигация: skip-link, Tab-порядок, ↑↓ в списках
- Контраст: body text ≥ 4.5:1, large text ≥ 3:1
