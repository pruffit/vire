00 · ГЛАВНОЕ ПРАВИЛО
У платформы нет своего цвета
Веб уже так живёт (packages/design-tokens не содержит поля accent) — платформенная оболочка нейтральна. Мобилка наследует это буквально: никакого фирменного мятного/любого другого «цвета бренда» нет. Цвет появляется только вместе с контекстом — профилем артиста (theme_tokens) или играющим сейчас релизом в плеере. Везде, где контекста нет (главная вне артиста, поиск, медиатека, настройки) — интерфейс полностью ахроматичный: только текст и подложки из палитры ниже.

Где акцент есть
Профиль артиста и всё внутри его контекста (посты, релизы на его странице) — цвет из theme_tokens. Полноэкранный и мини-плеер — цвет текущего релиза, гаснет при паузе/смене на трек без акцента.
Где акцента нет
Главная лента, поиск, медиатека, друзья/сообщения, настройки, любой список из разных артистов сразу. «Активное» состояние там красится нейтральным foreground #eae7e2 (сплошной круг), не цветом.

Rim по умолчанию — нейтральный белый блик 18%. Он становится цветным только когда панель физически лежит внутри контекста (профиль артиста / плеер с играющим релизом) — иначе это была бы скрытая протечка «фирменного цвета», которого не существует.

Реализация
CSS backdrop-filter в RN не существует. Панель = expo-blur's <BlurView intensity=60 tint="dark"> + оверлей-заливка поверх (даёт opacity/saturate, которых у BlurView нет отдельным параметром) + верхний градиент-блик + нижний rim — все три уже готовые CSS-слои из анатомии выше просто переносятся 1:1 как вложенные View. На Android — обязательно experimentalBlurMethod="dimezisBlurView", иначе на многих устройствах BlurView рендерит сплошной цвет без размытия.
Лимиты
Максимум 2 одновременных BlurView на экране (не 3 — Android дороже веба). Типичная пара — нав + мини-плеер; если открыт ещё и sheet поверх них, нижний слой на время открытия снэпшотится в статичную картинку (blur «замораживается»), а не остаётся живым. Blur ставится на паузу во время скролла списка под ним — восстанавливается через ~150мс после остановки.
ДА
Стекло — только на плавающих слоях: навигация, мини-плеер, шапки на скролле, sheets, composer, поиск, Поток, панели джема.
НЕТ
Стекло на карточках списков, пузырях чата, строках треков, любом плотном контенте. Стекло на стекле. Больше 2 BlurView разом.
Тумблер «Стеклянный интерфейс» в настройках (см. 05 · КОМПОНЕНТЫ) выключает BlurView разом на всём приложении — заливка становится непрозрачной #0b0908. Это и ручной opt-out, и автоматический fallback, если замер на устройстве показывает <50fps на живом экране с двумя блюрами.

Правила
Mono — только для меты: таймкоды, счётчики, статусы, коды, теги в верхнем регистре. Никогда для контента. Минимальный кегль — 10px (mono) и 11px (Manrope); на стекле — не ниже 11px и не легче 500.
