# VireGlass

Материал «жидкое стекло» для интерфейсов Vire. Сейчас реализован **только на Android**
внутри мобильного приложения.

| Документ | О чём |
|---|---|
| `architecture.md` | карта текущей реализации: слои, параметры, ограничения |
| `ADR-001-rendering-architecture.md` | решение по архитектуре рендеринга и доказательства |
| `benchmarks/` | замеры: стенд, протокол, результаты |
| `../architecture/vireglass-spec.md` | спецификация материала и стратегия по платформам |

## Известные ограничения

- **Настоящее стекло доступно только вне экранов** — таб-бару и мини-плееру. Внутри
  экрана оно деградирует до полупрозрачной плашки: положить стекло внутрь его же цели
  захвата нельзя, дерево RenderNode замыкается и рантайм падает. ADR-001 §2.
- **Стоимость линейна по числу поверхностей** (~4.3–5.2 мс на эмуляторе). Разделения
  работы между стёклами нет. `benchmarks/2026-08-28-scaling-emulator.md`.
- **Преломление требует Android 13+.** Ниже — равномерное увеличение, это лупа, не линза.
- **На реальном устройстве не измерялось ничего.** Все цифры — эмулятор с десктопной
  iGPU через трансляцию, debug-сборка. Переносить их на телефоны нельзя.
- **Геометрия считается дважды** (SKSL и AGSL), константа `BEVEL` синхронизируется вручную.

## Стенд

Стенд заменяет собой приложение и включается переменной окружения — по умолчанию выключен,
продовый путь не задевает.

```bash
# эмулятор обязательно с GPU, иначе замеры бессмысленны
emulator -avd VireMusic_Test -gpu host

cd apps/mobile

# зонды: какие пиксели получает createRuntimeShaderEffect (ADR-001 §3)
EXPO_PUBLIC_GLASS_LAB=1 npx expo start --dev-client

# сцены замера масштабирования (1 / 3 / 6 / 10 поверхностей)
EXPO_PUBLIC_GLASS_LAB=bench npx expo start --dev-client
```

Зонд `glass-lab` переключается по кнопке между тремя режимами: сырая выборка, выборка
с маркером живости шейдера, карта альфы. Последний однозначно показывает, пришло ли
в шейдер хоть что-нибудь.
