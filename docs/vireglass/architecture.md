## 2. Фактический стек слоёв

Композиция в `liquid-glass.tsx` — три физических слоя, снизу вверх:

```
┌─ Skia Canvas (SKSL)        поверхность: тень, фаска, Френель, блик, кромка, иконка
│                            рисуется НАД линзой, середина почти пустая
├─ GlassLensView (AGSL)      RenderEffect на вьюхе; шейдер семплирует своё содержимое
│  └─ BlurView (dimezis)     ребёнок: рисует В СЕБЯ контент экрана по blurTarget
└─ host View                 позиционирование, жесты
```

**Ключевая деталь, определяющая всё остальное:** `BlurView` — это *ребёнок*
`GlassLensView`. `RenderEffect` отдаёт шейдеру содержимое узла вместе с детьми, поэтому
в `content` приходит уже отрисованный размытый бэкдроп. Бэкдроп даёт **dimezis**,
а RenderEffect только его преобразует.

## 3. Сверка с целевой моделью A/B

Целевая модель Phase 2 — слой A (геометрия, фон не нужен) и слой B (оптика, фон нужен).
Фактическая раскладка ей соответствует, но **границей проходит не там, где ожидалось**:

| Компонент | Слой по модели | Где живёт фактически |
|---|---|---|
| SDF-маска формы | A | **дважды**: SKSL (`liquid-glass.tsx`) и AGSL (`GlassLensView.kt`) |
| Кромка/Френель | A | SKSL |
| Блик (2 источника) | A | SKSL |
| Тинт | A | SKSL |
| Эластичная деформация | A | SKSL + трансформ подложки (симметрично, вручную) |
| Тень, ореол | A | SKSL |
| Захват бэкдропа | B | **BlurView (dimezis)**, не RenderEffect |
| Блюр | B | BlurView |
| Преломление | B | AGSL |
| Хроматическая аберрация | B | AGSL |
| Сферическая аберрация | B | AGSL |

### Расхождение 1 — геометрия посчитана дважды

SDF формы вычисляется в двух шейдерах независимо:
- `GlassLensView.kt` → `sdRect` + `edgeNormal` (скруглённый прямоугольник, круг — частный случай);
- `liquid-glass.tsx` → радиальная геометрия по `length(q)`, только круг.

Константа `BEVEL = 0.18` продублирована в обоих и в комментарии помечена как обязанная
совпадать вручную. Расхождение констант = подложка и нарисованная поверх кромка описывают
разные стёкла.

### Расхождение 2 — поверхность умеет только круг

AGSL-линза поддерживает произвольный скруглённый прямоугольник (`u_half`, `u_corner`),
а SKSL-поверхность — только круг (`r = length(q) / R`). То есть панель мини-плеера
получает преломление прямоугольной формы, но поверхностной оптики к ней нет.

### Расхождение 3 — деформация синхронизируется вручную

Обратная деформация в SKSL и трансформ живой подложки (`lensStyle`) описывают один и тот
же закон, но реализованы порознь и обязаны совпадать. Комментарий в коде это фиксирует.

## 5. Жизненный цикл и ограничения

- **Гейт версии:** `createRuntimeShaderEffect` — Android 13+ (SDK 33). Ниже — аффинный
  `LOUPE` (лупа, не линза). Гейт отдаётся в JS константой `isGlassLensSupported`.
- **Overscan:** вьюха линзы в 1.55× больше круга — у кромки выборка уходит за его пределы
  (`EDGE_REACH = 1.3`), без запаса шейдеру нечего семплировать.
- **`visibility` трогать нельзя:** `dimezisBlurView` прекращает захват, когда вьюху прячут,
  и сам не оживает. Прятать допустимо только при полностью отсутствующем шейдере.
- **Рекурсия RenderNode:** цель блюра не должна содержать сам BlurView, иначе дерево
  замыкается (`SIGSEGV` в RenderThread). Защита — `BlurTargetScope`: потребитель внутри
  цели её не получает.
- **Следствие защиты:** стекло **внутри** экрана цели не получает и деградирует до
  полупрозрачной плашки. Настоящее стекло сегодня имеют только таб-бар и мини-плеер —
  они живут снаружи экранов.
- **Плотность:** все dp→px переводы в `GlassLensView.kt` через
  `context.resources.displayMetrics.density`; маска иконки строится в пикселях устройства
  (`PixelRatio.get()`), в dp мылила на 3x-экранах.
- **Ошибка компиляции AGSL** ловится в конструкторе и логируется: молчаливый фолбэк
  оставлял BlurView рисовать прямоугольник во всю вьюху без связи с симптомом.

## 6. Границы CPU/GPU

| Работа | Где |
|---|---|
| Маска иконки (offscreen Skia surface, `makeNonTextureImage`) | CPU/GPU, один раз на смену иконки |
| Униформы, пружины, жесты | CPU (Reanimated worklets, UI-поток) |
| SKSL-поверхность | GPU, каждый кадр |
| Захват бэкдропа (`dimezisBlurView`) | перерисовка дерева вьюх, **на каждое стекло** |
| Блюр | RenderEffect внутри BlurView |
| AGSL-линза, 6 выборок на пиксель | GPU, каждый кадр |

**Не измерено ничего.** Ни одного замера на реальном железе не проводилось —
эмулятор проекта до Phase 2 работал с `hw.gpu.enabled=no`.
