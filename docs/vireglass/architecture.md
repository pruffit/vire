## 2. Фактический стек слоёв

```
┌─ Skia Canvas (SKSL)        поверхность: тень, фаска, толщина, Френель, блик, кромка,
│                            тинт, дисперсия кромки, иконка; середина почти пустая
├─ GlassLensView (AGSL)      RenderEffect на вьюхе; преломление + сферическая
│  └─ BlurView (dimezis)     и хроматическая аберрации
└─ host View                 позиционирование, жесты
```

**Ключевая деталь, определяющая всё остальное:** `BlurView` — это *ребёнок*
`GlassLensView`. `RenderEffect` отдаёт шейдеру содержимое узла вместе с детьми, поэтому
в `content` приходит уже отрисованный размытый бэкдроп. Бэкдроп даёт **dimezis**,
а RenderEffect только его преобразует. Доказательство — ADR-001 §3.

## 3. Модель материала и её граница с рендерером

```
VireGlassMaterial + VireGlassGeometry      ЧТО такое стекло
            │
            ├── toLensProps ──────────►    пропы GlassLensView  ┐
            └── toSurfaceUniforms ────►    униформы SKSL        ┴ КАК Android это рисует
```

Материал не знает ни про Android, ни про Skia, ни про dimezis. Значения в dp считает
`geometry.ts`; перевод dp→px делает Kotlin (`displayMetrics.density`) для линзы, а SKSL
работает в dp по построению канваса.

**Тумблеры эффектов — это обнуление параметров**, а не варианты шейдера:
`refraction: false` даёт `refraction = 0, refractionScale = 1`. Так сравнение ON/OFF идёт
на одной программе. Исключения: `backdrop` (BlurView не монтируется) и `blur`
(интенсивность 0) — они решаются в компоненте.

## 4. Геометрия считается один раз

Общий сниппет `sdf.ts` конкатенируется в оба шейдера; исходник AGSL при этом собирается в
TypeScript и передаётся в `GlassLensView` пропом `shaderSource` (Kotlin компилирует и
кэширует по значению строки). Встроенной копии AGSL в Kotlin нет намеренно.

Из общей геометрии выводятся все краевые величины:

| Величина | Откуда | Что питает |
|---|---|---|
| `sd` | `vgScene` | маска, тень, ранний выход |
| `t` = `vgBevelT(sd, bevel)` | из `sd` | толщину, преломление, обе аберрации, ширину кромки, маску блика |
| `n` | `vgSceneNormal` | направление кромочных дуг, смещение выборки |
| `N` = `(n · slope(t), 1)` | из `n`, `t` | Френель, блик |

Прежние расхождения `architecture.md` (редакция Phase 2) закрыты:

- **Расхождение 1** (геометрия дважды, `BEVEL` вручную) — закрыто: текст SDF один, фаска
  приходит из материала.
- **Расхождение 2** (поверхность умеет только круг) — закрыто: поверхность работает на
  скруглённом прямоугольнике, круг и капсула — его частные случаи.
- **Расхождение 3** (деформация синхронизируется вручную) — **в силе**: обратная
  деформация в SKSL и трансформ живой подложки по-прежнему две реализации одного закона.
  Обе живут в `glass-surface.tsx` рядом, константа `MAX_STRETCH` одна.

## 5. Жизненный цикл и ограничения

- **Гейт версии:** `createRuntimeShaderEffect` — Android 13+ (SDK 33). Ниже — аффинная
  лупа. Гейт отдаётся в JS константой `isGlassLensSupported`.
- **Запас вьюх считается, а не задаётся коэффициентом:** `lensPadDp` = смещение выборки +
  обе аберрации + запас; `surfacePadDp` = вылет тени + ход перетаскивания. Прежние
  `OVERSCAN = 1.55` и `PAD_RATIO = 0.44` были константами независимо от материала.
- **`visibility` трогать нельзя:** `dimezisBlurView` прекращает захват, когда вьюху прячут,
  и сам не оживает. Прятать допустимо только при полностью отсутствующем шейдере.
- **Рассинхрон имён пропов JS↔Kotlin Expo проглатывает молча** — именно так преломление
  было выключено в проде целую фазу. Закрыто тестом-паритетом, который разбирает
  `GlassLensModule.kt` и `GlassLensView.kt` (`lib/__tests__/vireglass-material.test.ts`).
- **Рекурсия RenderNode:** цель блюра не должна содержать сам BlurView, иначе дерево
  замыкается (`SIGSEGV` в RenderThread). Защита — `BlurTargetScope`.
- **Следствие защиты:** стекло **внутри** экрана цели не получает и деградирует до
  полупрозрачной плашки. Настоящее стекло сегодня имеют только таб-бар и мини-плеер.
- **Ошибка компиляции AGSL** ловится и логируется; отдельно ловится рассинхрон униформ
  (`setFloatUniform` на несуществующее имя бросает `IllegalArgumentException`).

## 6. Границы CPU/GPU

| Работа | Где |
|---|---|
| Маска иконки (offscreen Skia surface, `makeNonTextureImage`) | CPU/GPU, один раз на смену иконки |
| Компиляция AGSL | один раз на смену текста шейдера (кэш по строке) |
| Униформы, пружины, жесты | CPU (Reanimated worklets, UI-поток) |
| Фильтр акселерометра | CPU, 20 Гц, только при `environment > 0` |
| SKSL-поверхность | GPU, каждый кадр |
| Захват бэкдропа (`dimezisBlurView`) | перерисовка дерева вьюх, **на каждое стекло** |
| Блюр | RenderEffect внутри BlurView |
| AGSL-линза, 6 выборок на пиксель | GPU, каждый кадр |
| Морфинг: нормаль конечными разностями | GPU, +4 вычисления SDF на пиксель, только на стенде |

**Замерено частично.** Прогон Phase 2.1 (`benchmarks/2026-08-28-scaling-device-release.md`)
мерил конвейер **без** RenderEffect — линза тогда не включалась. Стоимость Material v1
не измерена.
