**Сейчас есть:** Auth.js v5 (JWT, httpOnly), роли в `proxy.ts` (/dashboard,

## Справка: ответы на вопросы повестки (состояние на 10.06.2026)

**Как создаётся обратный отсчёт до релиза.** Артист создаёт релиз с датой в
будущем и жмёт «Запланировать» → статус SCHEDULED. Все публичные запросы
показывают SCHEDULED-релизы только когда `release_date <= now()` — т.е. релиз
«открывается» сам, без крона. До этого на странице артиста и главной висит
`CountdownBadge` (клиентский тик раз в секунду до release_date). При публикации
уходит рассылка подписчикам (queue notify-release → Resend).

**Безопасность** — см. блок 3: базовая модель здоровая (роли, валидация,
владение, presigned, верификация вебхуков), до прода нужны rate limiting,
security headers, бэкапы и аудит зависимостей.

**Авто-теги треков** — см. блок 2: сейчас BPM/key только из тегов файла,
mood — от слушателей, жанра нет. Автоанализ — отдельный этап работ.
