# Документация Vire

Карта всей документации проекта. Файлы лежат плоско (без вложенных папок), потому
что на них ссылаются `CLAUDE.md` и рабочая память по прямым путям. Этот индекс
группирует их по смыслу.

## Фундамент (видение и дизайн)

Три связанных документа — продуктовое видение, технический фундамент, модель данных.

- [**concept.md**](concept.md) — концепция и продуктовое видение: что решаем, четыре
  этапа развития, темизация, взаимодействие слушателя, волна, монетизация.
- [**architecture.md**](architecture.md) — технический фундамент: стек, структура
  монорепо, слои, потоки данных, деплой, отказоустойчивость.
- [**data-schema.md**](data-schema.md) — модель данных (Drizzle/PostgreSQL): сущности,
  связи, решения «на вырост».

## Принципы

- [**ui-principles.md**](ui-principles.md) — UI/UX-принципы: движение, цвет/токены,
  layout, типографика, доступность. Живой документ.

## Фичи (как сделано)

- [**features/**](features/README.md) — по файлу на каждую фичу: что делает, где код,
  env, ограничения. Правило: новая фича не готова без файла здесь.

## Безопасность

- [**security/owasp-top-10.md**](security/owasp-top-10.md) — проход по чек-листу
  OWASP Top 10 с фиксами.

## Эксплуатация

- [**deployment.md**](deployment.md) — деплой на один VPS (Timeweb): подготовка
  сервера, env, CI/CD по тегу `vX.Y.Z`, бэкапы, обновление.

## Роадмапы

- [**roadmap-1.0.md**](roadmap-1.0.md) — повестка до 1.0 («оставшиеся 10%»), актуальный.
- [**interactivity-roadmap.md**](interactivity-roadmap.md) — ✅ завершён; исторический
  журнал решений по интерактиву/UX.

## Внешнее (питч и тестирование)

- [**pitch.md**](pitch.md) — презентация площадки для артистов и слушателей.
- [**beta-testing.md**](beta-testing.md) — руководство для бета-тестеров: сценарии
  проверки и формат баг-репорта.
