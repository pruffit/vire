# VireGlass: линза по эталону Liquid Glass

Эталон и наблюдения — `docs/vireglass/reference.md`. Полигон — веб-стенд `/rnd`.

## Проблема

Снимки стенда рядом с 4K-кадрами Apple: у нас серая плёнка с тёмным контуром, сетка проходит
сквозь неё без изменений, кромочного света нет. Причины в модели, а не в настройках:

1. **Выборка у кромки уходит наружу** (`s = … + n * edgePush * t^2.6` в `lens-shader.ts`) —
   это вогнутая линза. У эталона выпуклая: кромка берёт фон изнутри формы.
2. **Смещение не выведено из формы стекла**: степенной множитель вместо преломления на профиле.
3. **Фаска и толщина не зависят от размера детали** — прямое противоречие эталону (M 7:02).
4. **Блик — Фонг по широкой маске фаски** в поверхности, а у эталона тонкая линия по силуэту
   с двумя противоположными дугами и цветом окружения.
5. Тело отвечает только за читаемость (затемнение под надпись), свет оно не концентрирует.

## Решение

### Профиль и преломление (линза, общий AGSL/GLSL)

Стекло — толстая пластина с закруглённым краем. `e = −sd` — расстояние от силуэта внутрь,
`w` — ширина закругления, `T` — толщина, `H` — высота у самого силуэта.

- Высота `z(e) = H + (T − H)·q(e/w)`, `q(x) = (1 − (1 − x)^4)^{1/4}` — выпуклый сквиркл,
  внутри полосы `e ≥ w` высота `T`, наклон ноль, смещения нет.
- Нормаль `N = normalize(n·z′, 1)`; луч сверху преломляется `refract((0,0,−1), N, 1/n)` и
  приходит на контент со сдвигом `z·T.xy/(−T.z)` — **внутрь**. У силуэта сдвиг `H·√(n²−1)`.
- Дисперсия — тот же `refract` с показателем по каналу (Коши, синий гнётся сильнее).
- Площадное интегрирование там, где сдвиг меняется быстрее пикселя, остаётся.

### Масштаб

`w` и `T` множатся на `k(r) = clamp(√(r/24 dp), 0.8, 2.4)`, `r` — меньший полуразмер. Потолок
`w ≤ 0.65 r`. Причины материала (`ior`, `thickness`, `bevel`) остаются причинами — масштаб
применяет геометрия, как сейчас она ограничивает фаску.

### Кромочный свет (линза)

Френель по фактическому наклону профиля: у силуэта `cosθ → 0`, отражение → 1, поэтому линия
тонкая сама. Отражается окружение: цвет окрестности (уже собирается) и ключевой свет
`max(d,0)^p + 0.45·max(−d,0)^p`, `d = dot(n, L)`. Где свет не падает, отражение затенено —
отсюда тёмная обводка. Направление света приезжает в линзу униформой `u_light`.

### Остальное — после линзы, по кадрам

Тело (концентрация света, Regular/Clear), тень, нажатие (свечение от пальца, рост),
появление через линзу. Порядок: линза → кромка → тело → взаимодействие → экраны стенда.

## Стенд

Новые фоны под эталонные кадры: горизонт (светлое/тёмное), свет сбоку на тёмном, цветная сцена
(«мак на небе», процедурно), дюны, абзац текста. Форма контрольного образца — капсула, круг,
скруглённый прямоугольник.

## Совместимость

- Имена и порядок униформ едут каналом; Kotlin применяет канал по именам (`applyChannel`) —
  новые униформы линзы правок натива не требуют. Контракт в `targets.test.ts` обновляется.
- Текст шейдера остаётся в подмножестве AGSL: `refract`, `inversesqrt`, циклы с константной
  границей.

## Приёмка

- Кадр стенда рядом с эталонным (горизонт, сетка, свет сбоку, цветная сцена): кромка берёт фон
  изнутри, линия блика тонкая, дуги противоположные, центр не смещён.
- `check:glsl`, `check:optics`, тесты пакета, typecheck/lint/test/build веба — зелёные.
- `docs/features/vireglass-web.md` и `docs/vireglass/README.md` описывают новую модель.
