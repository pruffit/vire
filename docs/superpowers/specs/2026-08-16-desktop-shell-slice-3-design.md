# Десктоп-клиент, срез 3 — автозапуск — дизайн

**Статус:** реализуется · **Основание:** `docs/multiplatform.md` §3.2, продолжение срезов 0-2

## Что это

Автозапуск VireMusic при входе в систему — последний несделанный пункт из списка
«что даёт десктоп поверх PWA практически» (`multiplatform.md` §3.2), не требующий
канала веб→Rust (в отличие от отложенного синка подписи трея среза 2) — целиком
нативная OS-фича, безопасный, самодостаточный срез.

## Решение

Официальный `tauri-plugin-autostart` (v2) — регистрирует/снимает автозапуск через
штатный Windows-механизм (registry `Run`-ключ), не пишет ничего своего руками.

**Управление** — чекбокс-пункт в существующем трей-меню (`apps/desktop/src-tauri/src/main.rs`):
«Запускать при входе в систему» (`CheckMenuItem`, Tauri v2 умеет чекаемые пункты трея).
Другой UI для этого не заводим — настроек-окна у приложения нет и не планируется в этом
срезе, трей — единственная поверхность управления, которая уже есть.

- Состояние чекбокса при старте — читается из `autostart_manager.is_enabled()`.
- Клик по пункту — toggle: `enable()`/`disable()`, обновить `checked` пункта меню.
- По умолчанию (первый запуск) — автозапуск **выключен**. Не включать его без явного
  действия пользователя — тихое добавление себя в автозагрузку без спроса — плохая
  практика, даже если технически безобидно.

## Явно НЕ в этом срезе

- Настройки-окно/полноценный UI предпочтений — трей-чекбокса достаточно
- Синк подписи трея play/pause (отдельная отложенная задача, требует IPC — не путать)
- Мини-плеер поверх окон, код-сайнинг, автообновление

## Проверка

`cargo tauri dev`: включить чекбокс в трее → проверить реально появившуюся запись
автозапуска (Windows: `reg query HKCU\Software\Microsoft\Windows\CurrentVersion\Run`
или Task Manager → вкладка «Автозагрузка») → выключить → запись пропадает. Не полагаться
на «плагин зарегистрировался без ошибки» — подтвердить фактическое присутствие/отсутствие
записи в реестре, как в предыдущих срезах (эмпирическая проверка, не предположение).
`cargo tauri build` — сборка не ломается с новым плагином.
