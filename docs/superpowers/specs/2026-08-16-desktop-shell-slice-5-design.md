# Десктоп-клиент, срез 5 — единственный экземпляр и память окна — дизайн

**Статус:** реализуется · **Основание:** продолжение срезов 0-4

## Что это

Два стандартных паттерна десктоп-приложений, оба — официальные Tauri v2 плагины,
оба чисто нативные (без канала веб→Rust):

1. **Единственный экземпляр.** Сейчас повторный запуск `vire-desktop.exe` (двойной клик по
   ярлыку, автозапуск + ручной старт и т.п.) откроет второе окно/процесс — неожиданно для
   пользователя и держит два вебвью с двумя HLS-плеерами разом. `tauri-plugin-single-
   instance` — второй запуск не создаёт новый процесс, а сигналит первому, который
   разворачивает/фокусирует своё окно (в т.ч. если было свёрнуто в трей срезом 4).
2. **Память размера/позиции окна.** Сейчас окно всегда стартует 1280×800 в дефолтной
   позиции ОС — если пользователь подвинул/растянул окно, это не переживает перезапуск.
   `tauri-plugin-window-state` — сохраняет геометрию (и, опционально, свёрнуто/максимизировано)
   между запусками автоматически, восстанавливает при следующем старте.

## Решение

Оба — официальные плагины `tauri-plugin-single-instance` и `tauri-plugin-window-state`,
подключаются как обычные Tauri-плагины (`cargo add`, `.plugin(...)` в `main.rs`).
`single-instance` — единственный плагин, чей `.plugin(...)` должен идти **первым** в
цепочке билдера (задокументированное требование самого плагина — если версия API этого
требует, свериться по факту, не по памяти). `window-state` — восстанавливает геометрию
через свой `.plugin(...)`, дальше окно можно создавать через builder как обычно
(некоторые версии плагина требуют явно вызвать `restore_state`/использовать
`WindowExt::restore_state` на созданном окне — свериться с актуальным API).

## Явно НЕ в этом срезе

- Сохранение прочего состояния приложения (том громкости, очередь и т.п.) — это уже
  персистится веб-стороной (Zustand `persist`), окно — только геометрия
- Настройка «запускать свёрнутым в трей» — отдельная опция, не в этом срезе

## Проверка

`cargo tauri dev` (или собранный `.exe`): запустить приложение дважды подряд — второй
запуск не создаёт новый процесс в `tasklist`, фокусирует существующее окно (в т.ч. если
оно было свёрнуто в трей срезом 4 — проверить и этот случай). Подвинуть/изменить размер
окна, закрыть процесс целиком (через «Выход»), запустить заново — окно появляется в
той же позиции/размере, не в дефолтных 1280×800. Эмпирически подтвердить оба сценария.
`cargo tauri build` — сборка с новыми плагинами не ломается.
