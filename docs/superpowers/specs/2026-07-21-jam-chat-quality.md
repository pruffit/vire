# Спека: качество джема и чата (2026-07-21, по юзер-тесту v1.29.0)

## Root cause

| # | Симптом | Причина |
|---|---|---|
| 1 | Джем невозможно запустить | `jam-room.tsx`: `onPlay={noop}` у строк очереди — хостовое управление не прошито (API playback play/pause/seek/track полный) |
| 2 | Поиск трека в джеме: «KOTLAEV»/«NATURE» → 0 | `packages/db/src/queries/search.ts` `searchAll`: треки матчатся только по `tracks.title` |
| 3 | Нет подсказок в «Добавить трек» | Панель показывает пустоту до 2 символов; любимые треки юзера не предлагаются |
| 4 | Кнопки шапки джема разъехались | `touchTargetClass('md')` = фикс `w-11 h-11` (круг под иконку) на кнопках С ТЕКСТОМ («Сохранить в плейлист», «Поделиться») — текст вне кнопки |
| 5 | Чат — чёрная дыра | Empty-state треда рендерится только при готовом `ck`; blocked-состояния (нет ключа собеседника / needsLink) — тонкая строка у низа под пустотой |
| 6 | /messages — узкая колонка в пустоте | Страница списка max-w-3xl, нет мессенджер-лейаута |
| 7 | Сайдбар: дубль «Друзья/Друзья», разнобой рейла | `library-sidebar.tsx`: subtitle-фолбэк = титулу; в свёрнутом виде плитки/аватары разных форм |

## Требования

1. **Джем играет**: хост кликает трек в очереди → `POST playback {kind:'track'}`;
   бар «сейчас играет» (обложка, название, play/pause для хоста; pause шлёт
   `{kind:'pause', positionMs: derivePositionMs(...)}`, resume — `{kind:'play',
   trackId, positionMs}`). Не-хост видит активный трек и статус, без кнопок.
2. **Поиск**: треки матчатся по названию трека ИЛИ имени артиста ИЛИ названию релиза.
3. **Подсказки**: при пустом запросе панель сразу показывает любимые треки юзера
   (сервер передаёт с страницы, ~8 шт, заголовок «Из любимых»).
4. **Шапка джема**: пилюли с текстом — `min-h-11 px-4`, никаких фикс-ширин; иконки-only
   остаются 44×44; на узких — компактно, ничего не вылезает. Контент комнаты — 
   осмысленная ширина (max-w-4xl центр), не пустыня.
5. **Мессенджер-лейаут**: `/messages` — двухпанельный на десктопе (слева список
   диалогов + DeviceLink, фиксированной ширины, свой скролл; справа тред или
   заглушка «Выберите диалог»), всё на полную высоту без футера. Мобилка: индекс —
   список, диалог — тред на весь экран (как сейчас). Активный диалог подсвечен.
6. **Состояния треда — по центру**: пустой тред, «нет ключа собеседника»,
   «подтвердите устройство» (со ссылкой на привязку/сброс) — центрированные
   состояния с иконкой и внятным текстом, а не строчка под пустотой.
7. **Сайдбар**: subtitle опционален (у «Друзья» без заявок — без подписи);
   свёрнутый рейл — единообразные плитки.

## Не делаем
- Не трогаем крипто-протокол, playback-механику синка, серверные роуты джема
  (кроме search-запроса в db).
