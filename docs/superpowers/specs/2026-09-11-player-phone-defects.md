# Экран плеера: пять дефектов, найденных на аппарате

Нашлись на Xiaomi 2311DRK48G (1220×2712, релизная сборка). На эмуляторе 1080×2400 часть
из них не воспроизводится — это и есть причина, по которой их не поймали раньше.

Фон экрана (`components/haze-ground.tsx`) НЕ трогаем: он требует отдельной переработки,
решение по нему принимается позже.

## 1. Шов резкости на стеклянной детали

Видно горизонтальный переход: верх поверхности размыт, ниже — резкая картинка, будто
бэкдроп захвачен наполовину.

Диагноз не закрыт: на аппарате не переснять (заблокирован), на эмуляторе не воспроизведён.
Идёт отдельным треком, в этот срез не входит.

## 2. Лишняя высота копится в одном месте

`coverRegion` — `flexGrow: 1` c `justifyContent: 'flex-end'`, а `artSize` упирается в
`contentWidth`. На аппарате выше макетных пропорций весь избыток оседает ВНУТРИ этой
области над обложкой: между шапкой и обложкой зияет провал, остальные отбивки остаются
макетными.

**Решение.** Избыток раскладывается по ВСЕМ вертикальным зазорам экрана пропорционально
их макетным величинам, а не достаётся одному. Считает это чистая функция — ей нужен тест,
потому что именно здесь ошибка тихо возвращает провал:

```ts
// lib/design/stack.ts
export function distributeSurplus(gaps: readonly number[], surplus: number): number[]
```

Вес зазора — его макетная величина: отбивка, которой в макете отведено 44, получает вдвое
больше добавки, чем та, которой отведено 22. Отрицательный избыток (низкий аппарат) не
раздаётся вовсе — там работает прежний механизм сжатия.

Зазоры экрана: воздух над обложкой, обложка→название, артист→прогресс,
прогресс→транспорт, транспорт→«ПОТОК», «ПОТОК»→низ.

## 3. Заголовок трека крупноват

`MOCK_TITLE_SIZE` 22 → 20. Кегль артиста не трогаем — пара уже разведена.

## 4. Панель текста песни

### (а) Не читается стеклом

`VIREGLASS_LYRICS_MATERIAL` — базовое стекло, и `GlassPanel` берёт его БЕЗ масштаба макета,
в отличие от навигации и мини-плеера. Панель растянута в размер обложки (на аппарате это
больше тысячи пикселей), а фаска осталась макетной — её доля от полуразмера втрое меньше
нарисованной, и кромки не видно. Ровно та же причина, по которой кнопка «ПОТОК» стояла
плоской плашкой.

**Решение.** Материал панели идёт через `useMockMaterial`, как у остальных деталей.

### (б) Не совпадает с обложкой

Рамка совпадает (`top`/`left`/`width`/`height` считаются по замеру обложки), а СКРУГЛЕНИЕ —
нет: панель берёт `radii.card`, обложка — `ms(MOCK_COVER_RADIUS)`. Радиус приходит снаружи,
из того же числа, что и у обложки.

### (в) Строки переключаются рывком

`Synced` меняет три `Text` мгновенно на смену `activeIndex`. Нужен плавный переход между
блоками: кросс-фейд со сдвигом вверх, длительность — из `motionDuration`, при
`useReduceMotion()` переход мгновенный.

## 5. Двойной тап лайкает вхолостую

```ts
like(trackId) {
  const current = get().state[trackId];
  if (current === undefined || current === true) return;   // ← молча ничего не делает
  write(trackId, true, current);
}
```

Пока лайк трека не загружен, `like()` выходит впустую. Анимация всплеска при этом уже
проиграна — жест отдал отклик, а лайка не случилось, и сердце не меняется. Это тот же
случай, под который в этом же сторе написан `toggleRemote` («трек может ни разу не
показывался в UI»).

**Решение.** Неизвестное состояние сначала догружается, потом ставится лайк — как в
`toggleRemote`. Тест на стор: `like()` при незагруженном состоянии доводит дело до конца,
а не выходит.
