# Срез 3 — контентные экраны (мобайл-фёрст) — дизайн

**Дата:** 2026-07-26 · **Программа:** `2026-07-22-mobile-first-program.md` (срез 3) ·
**Паттерны:** `docs/features/mobile-patterns.md`

## Задача

Довести до мобайл-фёрст четыре контентных экрана в узком вьюпорте (<768px):
профиль артиста, релиз, трек, профиль слушателя. Десктоп-плотность не трогаем
(тач-таргеты — через `pointer-coarse:`).

## Вывод разведки

Экраны уже адаптивны по существу: сетки с `grid-cols-1` фолбэком, hero-заголовки на
`clamp()`, паддинги с `sm:/lg:`. Болячки — **точечные**, не структурные. Релиз — чистый,
правок не требует.

## Границы (НЕ в срезе)

- **«Покупки» и табы на профиле** — Этап 2, purchase-UI намеренно отвязан от витрины
  (`purchased-track-row.tsx` не импортируется by design, CLAUDE.md). Не добавляем.
- **Общая обёртка `PageContainer`** (дубль `max-w-[120rem] …` в ~15 файлах) — рефактор
  ради рефактора, на мобилку не влияет; отдельной задачей, не здесь.
- **Крупные структурные переработки** hero/сеток — не нужны (уже адаптивны).

## Дефекты и решения

Все правки — только классы; логика не меняется.

1. **Тач-недоступное редактирование имени** (`profile-hero.tsx:230`). Карандаш
   `opacity-0 group-hover:opacity-40 hover:!opacity-100` — на таче (нет hover) невидим →
   смена имени недоступна. **Fix:** `pointer-coarse:opacity-100` + хит-зона 44px через
   `pointer-coarse:w-11 pointer-coarse:h-11 pointer-coarse:-m-1.5 inline-flex …`.

2. **Хлебные крошки трека переполняются** (`tracks/[trackId]/page.tsx:155`).
   `flex items-center gap-2` без переноса → длинные имя+релиз режутся `overflow-x-clip`.
   **Fix:** `flex flex-wrap items-center gap-2 min-w-0`, каждый `<Link>` — `truncate max-w-[16rem]`.

3. **`MetaRow` (длительность/BPM/тональность) без переноса** (`tracks/[trackId]/page.tsx:346`).
   **Fix:** добавить `flex-wrap`.

4. **Мелкие тач-таргеты <44px** (растим только на `pointer-coarse`, десктоп неизменен):
   - соц-ссылки артиста `h-7 min-w-7` → `pointer-coarse:h-11 pointer-coarse:min-w-11` (`page.tsx:406`);
   - «любимый момент» `w-8 h-8` → `pointer-coarse:w-11 pointer-coarse:h-11` (`waveform-player.tsx:134`);
   - отписка `w-7 h-7` → `pointer-coarse:w-11 pointer-coarse:h-11` (`followed-artists.tsx:84`);
   - `LikeButton` трека → `pointer-coarse:min-h-11` (`like-button.tsx:36`);
   - текст-кнопки «Задать»/«Привязать» → `pointer-coarse:min-h-11 inline-flex items-center`
     (`linked-accounts-client.tsx:59,102`).

5. **Корни артиста и профиля без `overflow-x-clip`** (`artists/[slug]/page.tsx:174`,
   `profile/page.tsx:44`). На релиз/трек уже есть (проверенный паттерн). **Fix:** добавить
   `overflow-x-clip` — защитная сетка от гориз-скролла документа (плюс п.2–4 убирают
   источники переполнения).

## Механизмы тач-таргета (по `mobile-patterns.md`)

- Видимые пилюли/кнопки с фоном (соц-ссылки, момент, отписка) — растут на таче
  (`pointer-coarse:w-11/h-11` или `h-11/min-w-11`): на мобилке больше — это цель программы.
- Иконки без визуального бокса, где важен футпринт (карандаш имени) — хит-зона с
  негативным маргином (`pointer-coarse:…-m-1.5`), футпринт не едет.
- Текст-кнопки в ряду — `pointer-coarse:min-h-11 inline-flex items-center` (высота хит-зоны).

## Тесты

`pointer-coarse` не воспроизводится → отдельные юнит-тесты были бы хрупкими
ассертами классов (шум). Не добавляем. Гарантия — существующий сьют (1153) +
`layout-shell` инвариант + гейты; визуальный QA (Playwright/локально) — за Danya.
