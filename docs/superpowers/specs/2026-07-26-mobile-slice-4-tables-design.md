# Срез 4 — таблицы дашборда и админки (мобайл-фёрст) — дизайн

**Дата:** 2026-07-26 · **Программа:** `2026-07-22-mobile-first-program.md` (срез 4) ·
**Паттерны:** `docs/features/mobile-patterns.md`

## Задача

Широкие таблицы (`min-w-[520..900px]`, гориз-скролл) → **карточный рефлоу на мобилке**.
Решение Danya (22.07/26.07): **общий механизм в примитиве `Table`** — один раз, покрывает
все админ-таблицы. Десктоп неизменён.

## Вывод разведки

- **Все админ-таблицы идут через один примитив** `Table/Thead/Th/Tr/Td` (`components/ui-kit.tsx`,
  реэкспорт в `components/admin/ui.tsx`): у каждой уже `overflow-x-auto` + `min-w-[…]`. Карточного
  рефлоу нет нигде (`md:table` — 0 совпадений). 8 файлов используют `<Table>`, ~62 `<Td>`.
- **Дашборд почти без `<table>`** — он на карточках/флексе, адаптивен. Тут таблиц не трогаем.
- Реальный баг дашборда: «Анонсы» — кнопки Изм./Удалить за `opacity-0 group-hover` (тач-недоступны).
- Мелочь: тач-таргеты иконок-действий ~28px (`playlist-admin-row`, `smart-link-list`, `ActionLink`);
  две формы с `grid-cols-2` без `sm:` (`track-edit-form`, `release-edit-form`).

## Механизм рефлоу (в примитиве)

Под `md` (<768px) таблица разворачивается в стек карточек-строк:
- `<thead>` скрыт (`hidden md:table-header-group`).
- `<table>`/`<tbody>`/`<tr>`/`<td>` → `block` (на `md` возвращаются к `table*`).
- `<tr>` на мобилке — карточка (рамка, паддинг, отступ снизу); на `md` — обычная строка с `border-b`.
- `<td label="…">` на мобилке рендерит **«подпись: значение»** (`flex justify-between`), подпись —
  та же типографика, что у `Th`. `<td>` **без `label`** → значение блоком на всю ширину (для
  первичной ячейки-заголовка карточки и футера-действий).
- **`min-w-[…]` гейтится под `md:`** — иначе на мобилке ширина форсит гориз-скролл и рефлоу не виден.

**Критично (Tailwind JIT):** `md:min-w-[Npx]` нельзя собирать интерполяцией в рантайме
(`md:${minWidth}` — сканер не увидит). Call-sites передают **готовый литерал** `minWidth="md:min-w-[Npx]"`.
Классы примитива (`md:table`, `[&_tbody]:block`, `md:contents` и т.п.) — литералы в исходнике, ок.

Значение-обёртка использует `md:contents` — на десктопе span-обёртка исчезает из лейаута, DOM
ведёт себя как раньше (десктоп-регрессий нет).

## Границы (НЕ в срезе)

- Дашбордные карточные списки (release-list, smart-link-list раскладка) уже адаптивны — раскладку
  не переписываем (только тач-таргеты действий).
- Беспоковых мобильных карточек под конкретную таблицу не делаем — общий механизм (решение Danya).
- Индикатор скролла админ-навбара (`SideNav no-scrollbar`, 10 пунктов) — отложено, вне «таблиц».

## Тесты

Примитив `Td` теперь имеет наблюдаемую в DOM логику (рендер подписи при `label`, обёртка значения)
— покрываем юнит-тестом (`Table`/`Td`: с `label` рендерит подпись+значение; без `label` — только
значение). Рефлоу — CSS (в jsdom media не воспроизвести), классы не ассертим. Существующий сьют
(1153) + гейты.
