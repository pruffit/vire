# Страницы релиза и трека: редизайн (полиш до нового языка + усиленный герой + текст на треке)

**Дата:** 2026-07-01
**Статус:** утверждено (развилки закрыты с пользователем)
**Тип:** фронтенд-полиш контентных экранов + извлечение общего кита. Без изменений core/db.
**Источник:** §2.7 (проход по экранам). Продолжает редизайн артиста
(`2026-06-30-artist-page-redesign-v2-design.md`) — поднимает релиз/трек до того же
визуального языка.

## Решения по продукту (закрыты с пользователем)

1. **Объём = «полиш + усиленный герой».** Поднять релиз/трек до нового языка
   (SectionHeader-разделители, `color-mix` вместо `opacity`/`white-x`, клампы
   заголовков, mono-ридаут, мобилка/тач-таргеты 44px), усилить ambient-герой
   обложки. **Структуру колонок сохранить** (липкая обложка слева / контент
   справа). НЕ полный ре-концепт (без full-bleed 120rem, без перестройки макета).
2. **Текст песни (LRC) на странице трека — да.** Синхронный текст рядом с волной,
   подсветка строки по таймкоду из плеера-волны. Скрыт, если у трека нет lyrics.

## Что не так с текущим (диагноз)

- Релиз/трек отстали от артиста: `opacity-40`/`bg-black/15`/`ring-white/[0.06]`/
  `hover:bg-white/5` — литералы вместо темо-`color-mix`; контраст и «характер»
  слабее, чем на новом артисте.
- Нет signature-разделителя `SectionHeader` (accent mono-лейбл + волосяная линия) —
  секции («Треки», «Liner notes», «Из релиза») безголовые/блёклые.
- Ambient-герой (`AmbientBackdrop`) — еле заметный размытый wash без accent-радиала;
  странице не хватает «лица», которое у артиста даёт `ArtistBanner`.
- Текст песни существует только в фуллскрин-плеере — на контентной (SEO-значимой)
  странице трека его нет.

## Общий кит (извлечение — устранить дубли ДО правки страниц)

### 1. `SectionHeader` → `apps/web/components/section-header.tsx`
Сейчас локальная функция на странице артиста (page.tsx ~633, помечена «кандидат на
вынос»). Вынести **дословно** (accent mono `tracking-[0.25em]` + `h-px flex-1`
линия `color-mix(in oklch, var(--artist-text) 14%, transparent)`), экспортировать,
**заменить локальную на импорт** в артисте. Потребители: артист, релиз, трек.

### 2. `LyricsScroll` → `apps/web/components/lyrics-scroll.tsx` (темизируемый)
Сейчас в `components/player/lyrics.tsx` с нейтральной палитрой (`text-foreground`/
`text-muted-foreground`). Вынести scroll+sync-логику в общий компонент с
параметрами:
```ts
{ lines: LyricLine[]; variant?: 'player' | 'artist'; trackId?: string;
  onSeekTo?: (t: number) => void }
```
- `variant='player'` (нейтральный, по умолчанию) — текущая палитра; плеер нейтрален.
- `variant='artist'` — активная строка `text-[var(--artist-text)]` крупнее,
  неактивные `color-mix(in oklch, var(--artist-text) 40%, transparent)`, синхро —
  `…text 28%…` с hover до 70%.
- `trackId` — гард синхрона: активную строку считаем только когда
  `usePlayerStore(s => s.track?.id) === trackId`; иначе active=-1 (статичный показ).
  В плеер-оверлее проп можно не передавать (текст всегда для играющего трека).
- `onSeekTo` — по умолчанию `controls.seek`. Клик по строке вызывает его; в плеере —
  seek. На странице трека обёртка передаёт «play-or-seek» (если трек не активен —
  `controls.play(track, queue, idx)` затем `seek`).
Сохранить доскролл к активной строке (внутри контейнера) и `key={trackId}` у
родителя для сброса. `components/player/lyrics.tsx` → переключить на общий компонент
(`variant='player'`), внешнее поведение (тоггл, ленивый fetch) не менять.

### 3. `AmbientBackdrop` — усилить (тот же компонент, оба потребителя — релиз+трек)
Добавить верхний **accent-радиал** поверх размытого wash (по образцу
`ArtistBanner`): `radial-gradient(ellipse 70% 60% at 50% 0%, color-mix(in oklch,
var(--artist-accent) 22%, transparent), transparent 70%)`. Чуть поднять заметность
размытой обложки в верхней зоне (без вреда читаемости контента ниже — нижний
градиент в `--artist-bg` сохранить). Grain-aware (grain рисуется поверх как раньше).
Это и есть «усиленный герой» при сохранённом макете.

## Релиз — `…/releases/[releaseId]/page.tsx` + `track-list.tsx`

Структуру (back-link → grid `[20rem_1fr]` → липкая обложка слева / `TrackList` +
`Liner notes` справа) **сохранить**. Меняем:
- Контейнер остаётся центрированным (`max-w-6xl`) — это здравая ширина чтения для
  одноколоночного трек-листа; full-bleed растянул бы строки нечитаемо.
- Обёртки секций «Треки» и «Liner notes» → `SectionHeader`. (Сейчас у «Треки»
  заголовка нет вовсе, у «Liner notes» — блёклый `opacity-30`.)
- Заменить `opacity-*`/`white-x` → `color-mix(in oklch, var(--artist-text) NN%)`:
  back-link, тип/год/жанр, описание, mono-счётчик, liner notes.
- Заголовок релиза — кламп кегля как у артиста (fluid, не overflow на длинных).
- `TrackList`/`TrackRow`: `hover:bg-white/5`→`hover:bg-[color-mix(...text 7%)]`,
  активная строка фон тем же mix; ряд `min-h-11` (тач-таргет 44px; сейчас `py-2.5`
  ~40px). Стрелка-переход и логика play/toggle — без изменений.

## Трек — `…/tracks/[trackId]/page.tsx`

Структуру (breadcrumb → grid → липкая обложка/мета слева / волна + «Из релиза»
справа) **сохранить**. Меняем:
- Токенизировать поверхности: карточка волны и «Из релиза»
  `bg-black/15 ring-white/[0.06]` → `bg-[color-mix(...text 4%)]` +
  `ring-[color-mix(...text 8%)]`; ряды `hover:bg-white/5`→ mix; `opacity-*`→ mix.
- Заголовок — кламп как у артиста.
- **НОВОЕ: секция «Текст»** (между волной и «Из релиза»):
  - Сервер уже имеет `track.lyrics: LyricLine[] | null` (из `getWithTracks`,
    parsed) — **без доп. запроса, рендерим серверно** (плюс к SEO).
  - Рендерить `<section>` с `<SectionHeader label="Текст" />` только если
    `track.lyrics?.length`. Внутри — клиентский `track-lyrics.tsx`, оборачивающий
    общий `LyricsScroll variant='artist' trackId={track.id}` и передающий
    `onSeekTo` = play-or-seek (если трек не активен — `controls.play(playerTrack,
    queue, idx)`, затем `seek`).
  - Синхрон бесплатен: `LyricsScroll` читает `currentTime` из того же глобального
    стора, что и волна; гард `trackId` исключает ложную подсветку под чужой трек.
  - Порядок правой колонки: Волна → Текст → «Из релиза».
- «Из релиза» список и waveform-плеер внутри — логику не трогаем, только токены
  поверхностей/ховеров.

## Архитектура и слои

Чистый фронт (FSD: `app → components(shared)`). `packages/core`/`packages/db` не
трогаем — `track.lyrics` уже отдаётся. Новых запросов нет, бизнес-логики в
компонентах нет. Переиспользуем: `SectionHeader` (вынос), `LyricsScroll` (вынос),
`AmbientBackdrop` (усиление), `ZoomableCover`, `ReleaseHeroPlay`,
`ReleaseShareButton`, `TrackWaveformPlayer`, `MoodBadges`, `LiveListeners`,
`AddToPlaylistButton`, `ExplicitBadge`, `PlayingBars`, форматтеры.

## App-shell (инвариант)

Без `min-h-screen`/`h-screen`; страница `min-h-full`; единственный скроллер —
`#main-content`; sticky-колонка внутри него. Тест `layout-shell.test.ts` зелёный.

## Движение / производительность

`Stagger`/`animate-fade-up` как есть (де-промоут композита после анимации; без
висящих `transform`/`will-change` — память про scroll-jitter). Лишних ререндеров не
плодить: `LyricsScroll` подписан на `currentTime` точечным селектором (как сейчас).

## Краевые случаи

- Нет lyrics → секция «Текст» не рендерится.
- Несинхронизированный текст (plain, `t:null`) → строки статичные, без подсветки,
  не кликабельны (seek недоступен) — как в плеере.
- Трек играет другой/ничего → текст статичный, клик по строке запускает этот трек
  с таймкода (play-or-seek). PROCESSING-трек → плеера нет, текст можно показать
  статично (если есть), seek недоступен.
- Длинные заголовки релиза/трека → кламп кегля (без overflow).
- Нет обложки → текущие фолбэки; ambient-радиал работает и без обложки (accent).
- Гость → лайк read-only, play/follow как сейчас.
