# Мобайл-фёрст база — программа работ (декомпозиция)

**Дата:** 2026-07-22
**Заказ:** Danya, 21.07.2026 — «мобайл-фёрст UX/UI-база для всего сайта».
**Планка:** Impeccable по умолчанию, `audit:design` как гейт наравне с typecheck/test.

## Рамки (что НЕ обсуждается)

- **App-shell остаётся.** Документного скролла не будет (решение 21.07). Высоту даёт
  единственная скролл-область, `min-h-screen`/`h-screen` на страницах/лейаутах запрещены.
- **Браузерный хром на мобилке не прячем** (Яндекс Браузер не умеет PWA/WebAPK) —
  компенсируем качеством UX в минимальном вьюпорте. База ляжет в будущие нативные/обёртки.
- Раздел desktop/mobile — брейкпоинт `md` (48rem/768px), как уже зашит в шелле.

## Продуктовые решения (закрыто с Danya, 22.07)

1. **Порядок:** сначала фундамент паттернов (Срез 0), затем раскатка по экранам.
2. **Тач-таргеты:** через `pointer:coarse`-вариант — 44px на таче, десктоп-плотность сохраняется.
3. **Меню действий:** единый примитив — bottom-sheet на таче, поповер на десктопе (по pointer-типу).
4. **Таб-бар:** пересмотреть (не просто улучшать плитки медиатеки). Конкретика — в спеке Среза 0.

## Декомпозиция на срезы

Каждый срез — отдельный цикл `vire-loop` (spec → plan → impl → review → ship), свой тег/релиз.

| # | Срез | Суть | Зависит от |
|---|------|------|-----------|
| **0** | **Фундамент паттернов** | BottomSheet-ядро + `AdaptiveMenu` (sheet/popover), тач-таргеты в UI-ките (pointer:coarse), ревизия таб-бара, тач-аффорданс рейлов, компактный топ-бар, `docs/features/mobile-patterns.md` | — |
| 1 | Трек-действия и списки | share / в очередь / в плейлист → `AdaptiveMenu`; тач-таргеты трек-строк; триггер add-to-playlist 32→44 | 0 |
| 2 | Плеер | мини-бар/фуллскрин/скраб/очередь — мобильная полировка | 0 |
| 3 | Контентные экраны | артист / релиз / трек / профиль — узкий вьюпорт, компактные шапки, плотность | 0 |
| 4 | Дашборд + Админка | широкие таблицы (`min-w-[620..900px]` гориз-скролл) → карточный рефлоу на мобилке | 0 |
| 5 | Соц / app-screen | Джем / Сообщения / Друзья — мобильный UX + обнаружимость по новой навигации | 0 |
| 6 (опц.) | Каталоги / поиск / главная | финальная полировка плотности и аффордансов | 0–1 |

**Почему фундамент первым:** срезы 1–6 применяют примитивы (AdaptiveMenu, тач-таргеты,
аффордансы) — без них раскатка плодит дубли и разъезжается. Danya подтвердил порядок.

**Проверка примитивов внутри Среза 0:** BottomSheet-ядро уже имеет живого потребителя
(`QuickLookSheet`), `AdaptiveMenu` в Срезе 0 заводится минимум на один реальный вызов
(track-share или track-queue-menu) — примитив не уезжает непроверенным в раскатку.
