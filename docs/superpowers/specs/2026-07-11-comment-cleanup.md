# Чистка комментариев по монорепо (2026-07-11)

## Проблема

~2900 строк комментариев на ~44k строк кода. Комментарии-«почему» разрослись в
эссе на 5–9 строк, рядом мусорные комментарии-«что» и нарратив правок. Код тяжело
читать.

## Цель

Сократить объём комментариев в разы. Поведение кода НЕ меняется — диф состоит
только из удалённых/сокращённых комментариев и (точечно) дополнений в `docs/`.

## Критерии

### Удалять полностью
- Пересказ кода («что делает следующая строка»): `// сразу, не дожидаясь интервала`,
  `// сбрасываем стейт`, `// вызываем сервис`.
- Нарратив изменений/ревью: ссылки на версии (`v1.11`), «см. память проекта»,
  «оставлено для…», ссылки на пункты спек (`B4/D2`), «уже один раз сломалось».
- Дубли того, что уже описано в CLAUDE.md или `docs/features/*.md`.
- JSDoc, который просто повторяет имя функции/параметров.

### Сжимать до 1–2 строк
- Неочевидное «почему», без знания которого правка сломает поведение: race/staleness
  guards, защита от известного бага браузера/либы, неочевидный порядок операций,
  ограничение спеки (append-only enum и т.п.). Оставить суть-ограничение, убрать
  историю и рассуждения. Пример:
  - Было (6 строк): «Резюм восстановленного трека… duration уже персистится… иначе
    мини-бар на кадр покажет 0:00… ждём сеть…»
  - Стало (1 строка): `// на резюме duration не сбрасываем — иначе кадр 0:00/0:00 до durationchange`

### Выносить в docs
- Знание уровня фичи/системы (как устроен буфер волны, жизненный цикл play-event,
  правила краевых зон ScrollRow, композит-слои и дрожание скролла) — если его нет в
  соответствующем `docs/features/*.md`, добавить туда короткий раздел «Нюансы
  реализации» и в коде оставить максимум одну строку-указатель или ничего.
- Карта соответствия: плеер → `player.md`, волна → `wave.md`, подборки →
  `curated-playlists.md`, жанры → `auto-genre.md`, остальное — по списку `docs/features/`.

### Не трогать
- `eslint-disable`, `@ts-expect-error`, `@ts-ignore`, директивы (`'use client'`),
  shebang, лицензии.
- Однострочные секционные заголовки в длинных файлах (`// ─── Буфер волны ───`).
- Тестовые файлы — вне скоупа (чистим только продовый код).
- Код — вообще: ни переименований, ни форматирования, ни «заодно поправлю».

## Скоуп

`apps/web`, `apps/worker`, `packages/{core,db,ui,api-client,api-contracts}` —
все `.ts/.tsx` кроме `*.test.*`.

## Верификация

Гейты: typecheck (web/core/db), lint, check:routes, test, build. Диф — только
комментарии/доки: `git diff -w` не должен содержать изменённых строк кода.
