# Срез 6 (опц.) — Каталоги / поиск / главная: дизайн

**Дата:** 2026-07-26
**Цикл:** vire-loop, финальный срез программы мобайл-фёрст (`2026-07-22-mobile-first-program.md`).
**Тема:** «финальная полировка плотности и аффордансов». Модель: Opus (дизайн) → Sonnet (реализация + самокритика).

## Контекст

Рекон (Explore) по главной / `/artists` / `/releases` / `/search`: нарушений app-shell
нет (`min-h-screen`/`h-screen` отсутствуют), дефолтных серых текстов нет, `key={i}` только
в статичных скелетонах. Рельсы главной уже на `ScrollRow` (Срез 0). Основная работа —
**сквозные тач-таргеты мелких контролов + консистентность аффордансов + точечная плотность**.

## Продуктовое решение

Срез — полировка в рамках заявленной темы; продуктовой развилки нет, действуем по
разумным дефолтам. Плотностные изменения главной — **mobile-only** (`sm:` возвращает
десктоп), обратимы. Полную консолидацию 3 реализаций карточки артиста (разное поведение,
hover-preview только на главной) в этот срез НЕ берём — отложено в UI-бэклог как рефактор.

## Рамки

**В срезе (сгруппировано по типу):**

### A. Тач-таргеты «пилюль» (сквозной фикс — главный выигрыш)
Мелкие пилюли фильтров/сортировки/тегов (24–32px) на 4 экранах → 44px на таче через
общий хелпер (десктоп-плотность сохраняется):
- `wave-chips.tsx` — чипы «Потока» (главная).
- `artist-catalog.tsx` — кнопки сортировки + жанр-чипы.
- `releases/page.tsx` — табы сортировки.
- `search-releases-section.tsx` — жанр-чипы поиска.
Ввести общий `touchPill` рядом с `touchTargetClass` (`components/popover.tsx`) — не плодить
разрозненные литералы.

### B. `Section` «Показать все» (тиражируемая точка)
`components/listener/section.tsx` — ссылка-действие ~16–18px тап → хит-зона 44px на таче
(негативный маргин, чтобы не сдвигать хедер). Один фикс покрывает все секции главной.

### C. Поля поиска
- `global-search.tsx` — `variant="page"` input `h-9` → `pointer-coarse:h-11`; кнопка-иконка
  поиска (`right-3`, микро-хитзона) → реальная 44px хит-зона (`touchTargetClass`).
  `onMouseDown` в дропдауне НЕ трогать (осознанный порядок до blur; смена на onClick = риск регресса).
- `artist-catalog.tsx` — сырой `<input>` → переиспользовать `@vire/ui` `Input` (даёт
  `pointer-coarse:h-11` даром); если стили сильно расходятся — добавить `pointer-coarse:h-11`.

### D. Консистентность аффордансов
- `home/cover-rail.tsx` — сырой `overflow-x-auto` → `ScrollRow` (fade-маска/шевроны как у соседей).
- `artist-catalog.tsx` жанр-ряд — сырой `overflow-x-auto` → `ScrollRow`.
- Забытый `pointer-coarse:opacity-100` на hover-плей-оверлеях (правило mobile-patterns.md):
  `release-quick-look.tsx`, `home/cover-rail.tsx`, `listening-now.tsx`.

### E. Плотность (mobile-only)
- `featured-release.tsx` — `h-96` → `h-72 sm:h-96` (хиро не съедает весь экран на SE).
- `app/(listener)/page.tsx` — `space-y-16` → `space-y-10 sm:space-y-16`.
- `search/page.tsx` — сетка артистов `grid-cols-3` → `grid-cols-2 sm:grid-cols-3 …`
  (консистентно с `/artists`, крупнее тап на 320px).

### F. Мелкие лайк-кнопки
- `editorial-playlist-card.tsx` — лайк без хит-зоны → `touchTargetClass`.
- `release-quick-look.tsx` — строки треков в quick-look-шите (~36px) → тач-таргет.

**НЕ в срезе (бэклог):**
- Консолидация карточки артиста (3 реализации → 1 общий компонент) — рефактор, отдельно.
- `ArtistHoverChip` hover-preview на таче (не критично — `Link` работает).
- Вложения в чате (из Среза 5).

## Принципы применения

- Тач-таргеты — `pointer-coarse:`, десктоп-плотность не трогаем ([[mobile-patterns]]).
- **Общий хелпер `touchPill`** — не разрозненные литералы (decompose-reuse).
- Переиспользовать `@vire/ui` `Input`/`Button` вместо сырых контролов, где чисто.
- Плотностные правки — только mobile (`sm:` восстанавливает десктоп).
- App-shell неизменен; Impeccable по умолчанию; `audit:design` — гейт.

## Критерии готовности

- Все пилюли/чипы/табы сортировки, ссылки «Показать все», поля поиска ≥44px на таче.
- `CoverRail` и жанр-ряд артистов дают тач-аффорданс горизонтального скролла как соседи.
- Плей-оверлеи видны на таче.
- Главная на 320–375px ощутимо плотнее (хиро/отступы), десктоп-вид не изменился.
- Все 6 гейтов зелёные.
