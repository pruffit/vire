# План — локальные файлы в глобальном плеере (02.08.2026)

Вечеринка уже умеет играть файл с устройства-колонки (срез C, `lib/jam/sources/local-source.ts`).
Здесь то же самое приходит в обычный плеер: кинул файл — он встал в очередь рядом с
каталожными треками, транспорт/громкость/очередь общие. Ничего никуда не заливается.

## 1. Реестр файлов — общий, не party-специфичный

`apps/web/lib/party/local-files.ts` → `apps/web/lib/local-files.ts` (переезд без изменения
логики). Обновить импорты: `lib/jam/sources/local-source.ts`, `party-local-file-button.tsx`,
`party-room.tsx`, тесты. Каталог `lib/party/` после переезда пуст — удалить.

## 2. Модель

`PlayerTrack` (`store/player.ts`) получает `localFileId?: string`. Признак «локальный» —
наличие этого поля; `id` остаётся уникальным ключом очереди (берём тот же id файла).

**Локальные позиции не персистятся.** В `partialize` фильтровать `queue`/`originalQueue`/
`track` от позиций с `localFileId`: blob не переживает перезагрузку ни в одном браузере,
кроме Chromium с явным разрешением — фантомная строка в очереди хуже её отсутствия.
Если текущий трек локальный — персистить очередь без него и `track: null`.
`sliceQueueForPersist` работает уже по отфильтрованному массиву, иначе окно съезжает.

## 3. Движок

`lib/player/audio-engine.ts`, ветка в `attachAndPlay`:

- локальный трек → манифест не запрашиваем, hls не поднимаем: `audio.src = URL.createObjectURL(file)`,
  `hasAudio: true`, `waveformPeaks: null`; созданный URL освобождать при следующей загрузке
  (держать один `localObjectUrl` на движок, как в `local-source.ts`);
- файла нет в реестре (перезагрузка, чужое устройство) → `audioError: true` + переход
  к следующему треку, а не зависший плеер;
- **никаких play-events и heartbeat для локальных**: `startHeartbeat`/`flushPlayEvent` —
  только для каталожных, иначе на несуществующий trackId полетят 404 и мусор в аналитику;
- `maybePrefetchNextManifest` пропускает локальную следующую позицию;
- волна: буфер к локальному треку не запрашиваем (`growWaveBuffer` требует каталожный
  `track.id`) — при локальном текущем треке волна просто не растёт.

Проверить, что `resumeRestored` не пытается поднять локальный трек (его не будет в persist).

## 4. Как добавить — две двери

1. **Кнопка в панели очереди** (`components/player/queue-panel.tsx`): «Файл с устройства».
   Переиспользовать существующий `PartyLocalFileButton`, переехав им в
   `components/local-file-button.tsx` (проп `onPick`, стили — как у соседних кнопок панели).
2. **Перетаскивание файла в окно** — новый клиентский компонент
   `components/local-file-drop.tsx`, смонтирован в app-shell рядом с плеером:
   `dragenter/dragover/drop` на `window`, фильтр по `type.startsWith('audio/')` и по
   расширениям, полноэкранный оверлей-подсказка «Отпустите — добавим в очередь» только
   пока тянут файл. HTML5 DnD не конфликтует с dnd-kit (тот на pointer events).
   Несколько файлов за раз — все в очередь, порядок как в `dataTransfer.files`.

Обе двери зовут `controls.enqueue(tracks, 'end', { source: 'direct' })`; при пустом
плеере `enqueue` сам ведёт себя как `playQueue` (поведение уже есть). Тост: «Добавлено
в очередь: N».

Название трека — имя файла без расширения, исполнитель — пусто (метаданные из тегов
не читаем, это отдельная история). Длительность — из `<audio>`, как в
`party-local-file-button.tsx`.

## 5. UI-мелочи, которые нельзя забыть

- Локальная позиция в очереди/мини-баре: обложки нет — нейтральный плейсхолдер, бейдж
  источника переиспользовать из `components/jam/source-badge.tsx` (вынести, если он
  завязан на джем-типы) либо простая иконка файла.
- Лайк/ссылки на артиста и релиз для локальной позиции не рендерятся (поля и так
  опциональны — проверить, что ничего не падает на `undefined`).
- Мобилка: кнопка в панели очереди с тач-таргетом `min-h-11`.

## 6. Тесты

- `partialize`: локальные позиции не попадают в персист; текущий локальный трек →
  `track: null` и очередь без него; `queueIndex` остаётся валидным.
- Движок (`audio-engine`): локальный трек не дёргает `fetchManifest`, не шлёт
  play-event/heartbeat; отсутствующий файл → `audioError` + `next()`.
- `local-file-drop`: файл нужного типа добавляется, чужой (image/pdf) игнорируется,
  оверлей появляется только во время drag.
- Кнопка: имя файла без расширения становится названием.

## 7. Гейты

`typecheck` (web/core/db) · `lint` · `check:routes` · `test` · **`audit:design`** · `build`.

## Ограничения

- Файл живёт до перезагрузки вкладки; в очереди он не переживает F5 сознательно.
- Теги (артист/альбом/обложка) не читаем — только имя файла и длительность.
- Файл не уходит на сервер и не виден другим устройствам (в джеме — только колонке).
- Комментарии — только неочевидное «почему», 1–2 строки.
