# E2EE-чат (spec 2) — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to
> implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Перевести чат 1:1 (§11.5) в end-to-end шифрование — сервер хранит/релеит только
шифротекст и читать сообщения не может; мультидевайс через привязку устройства 6-значным кодом.

**Architecture:** X25519. Ключ диалога `CK = BLAKE2b(DH(ikPriv_self, ikPub_other) ‖ sorted
ikPubs)` выводится на клиенте из личных ключей обоих друзей — на сервере ключей диалога нет.
Сообщение — `crypto_secretbox(text, nonce, CK)`. Личный ключ генерится молча, живёт в IndexedDB,
переезжает на новое устройство эфемерным DH + SAS (6 цифр). Вся крипта — клиентская
(`apps/web/lib/e2ee/*`, libsodium); сервер оперирует непрозрачными блобами и публичными ключами.

**Tech Stack:** libsodium-wrappers (браузер), Drizzle/Postgres, Redis (link-сессии), Next 15
App Router, существующий SSE/Redis-pub-sub realtime.

**Спека:** `docs/superpowers/specs/2026-07-19-e2ee-chat-design.md` — читать перед началом.

## Global Constraints

- **Server-blind (критично):** плейнтекст сообщения НИКОГДА не покидает клиент и не попадает в
  БД/логи/уведомления. `messages.body` — шифротекст (base64). Любой путь, где сервер видит
  плейнтекст, — дефект.
- **Приватный ключ (`ikPriv`) на сервер в открытом виде не уходит никогда.** На сервере — только
  публичные ключи (`ikPub`) и эфемерные блобы привязки.
- **CK не хранится нигде** — только выводится из DH на клиенте.
- **Крипта только в `apps/web/lib/e2ee/*`** (libsodium/WASM, браузер). `packages/core` — чистое,
  без libsodium. Чистые функции (base64, digits6, safety-number, size-guard) — pure TS, тестируемы.
- **E2EE обязателен для всех 1:1.** Плейнтекст-режима нет.
- **Плейнтекст-длину (1–4000) валидирует клиент** до шифрования; сервер валидирует байтовый
  размер шифротекста (бонд `CIPHERTEXT_MAX_BYTES = 8192`).
- **Уведомления spec-1 (контентless) НЕ трогаем** — они совместимы.
- **Vire:** нет `min-h-screen`/`h-screen`; минимум комментариев (только «почему», 1–2 строки);
  нет `any` без причины; нет JS-`Date` в raw-`sql` (считать в SQL); мобилка обязательна, тач ≥44px;
  optimistic UI. Версия в двух местах; lockfile при изменении deps. Гейты все зелёные.
- **Ветка `feat/social-friends`.** Мёрж в `main` — по явной команде. В прод не катим.

**Files:**

**Interfaces:**

- Produces: `deriveCK(ikPrivSelf: Uint8Array, ikPubOther: Uint8Array, ikPubSelf: Uint8Array):
  Uint8Array`; `encryptMessage(plaintext: string, ck: Uint8Array): { ciphertext: string; nonce: string }`;
  `decryptMessage(ciphertext: string, nonce: string, ck: Uint8Array): string | null` (null если не бьётся).

- [ ] Step 1: Падающий тест: две identity-пары (A,B). `ckA = deriveCK(A.priv, B.pub, A.pub)`,
  `ckB = deriveCK(B.priv, A.pub, B.pub)` → `ckA` равен `ckB`. `enc = encryptMessage('привет', ckA)`;
  `decryptMessage(enc.ciphertext, enc.nonce, ckB) === 'привет'`. Порча nonce → `decryptMessage` → null.
- [ ] Step 2: Реализация (вызывающий гарантирует `await sodiumReady()`; `sodium` импортируется
  напрямую, base64/utf8 — из `./sodium`):
```ts
import sodium from 'libsodium-wrappers';
import { toB64, fromB64, utf8, fromUtf8 } from './sodium';
// personal-ключ BLAKE2b ровно 16 байт (min keybytes) — 15-символьная метка + \0
const CK_KEY = utf8('vire-chat-ck-v1\0');
function compareBytes(a: Uint8Array, b: Uint8Array): number {
  const n = Math.min(a.length, b.length);
  for (let i = 0; i < n; i++) if (a[i] !== b[i]) return a[i] - b[i];
  return a.length - b.length;
}
function concat(...arrs: Uint8Array[]): Uint8Array {
  const total = arrs.reduce((s, a) => s + a.length, 0);
  const out = new Uint8Array(total); let o = 0;
  for (const a of arrs) { out.set(a, o); o += a.length; }
  return out;
}
export function deriveCK(ikPrivSelf: Uint8Array, ikPubOther: Uint8Array, ikPubSelf: Uint8Array): Uint8Array {
  const shared = sodium.crypto_scalarmult(ikPrivSelf, ikPubOther);
  const [low, high] = compareBytes(ikPubSelf, ikPubOther) < 0 ? [ikPubSelf, ikPubOther] : [ikPubOther, ikPubSelf];
  return sodium.crypto_generichash(32, concat(shared, low, high), CK_KEY);
}
export function encryptMessage(plaintext: string, ck: Uint8Array) {
  const nonce = sodium.randombytes_buf(sodium.crypto_secretbox_NONCEBYTES);
  const c = sodium.crypto_secretbox_easy(utf8(plaintext), nonce, ck);
  return { ciphertext: toB64(c), nonce: toB64(nonce) };
}
export function decryptMessage(ciphertext, nonce, ck) {
  try { return fromUtf8(sodium.crypto_secretbox_open_easy(fromB64(ciphertext), fromB64(nonce), ck)); }
  catch { return null; }
}
```
  (`compareBytes` — лексикографическое сравнение Uint8Array; `crypto_generichash(outlen, msg, key)` —
  ключ 16–64 байт как «personal/keyed» хеш. Импортировать `sodium` напрямую; тесты вызывают
  `await sodiumReady()` в `beforeAll`.)
- [ ] Step 3: Тест PASS: `pnpm --filter @vire/web test -- e2ee/conversation`.
- [ ] Step 4: Commit `feat(e2ee): вывод ключа диалога из DH + secretbox сообщения`.
