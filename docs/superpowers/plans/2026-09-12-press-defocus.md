# План: расфокус краски под пальцем

Спека — `docs/superpowers/specs/2026-09-12-press-defocus.md`.

1. **Шейдер поверхности** (`packages/vireglass/src/surface-shader.ts`).
   Константа `VG_INK_DEFOCUS` в тех же единицах, что `VG_INK_DEPTH` (координаты сцены), и
   ветка вокруг обеих выборок краски: при `u_touchPress` выше порога — крест из четырёх
   отсчётов плюс центр с двойным весом, иначе прежняя одиночная выборка. Смещение
   прибавляется к `inkUv` ДО умножения на `u_iconScale` — масштаб общий для координаты и
   смещения.

2. **Гейт оптики** (`packages/vireglass/scripts/check-optics.mjs`).
   Третье обещание рядом с «окном» и «предметом»: сцена с маской краски (вертикальная полоса
   даёт кромку, по которой резкость и меряется), два прогона — без касания и с `press = 1`,
   метрика — максимум модуля разности соседних пикселей поперёк кромки. Под пальцем она
   обязана упасть заметно, в покое — совпасть с прежним поведением.

3. **Тесты ядра** (`packages/vireglass/src/__tests__/`).
   Проверять текстом шейдера нечего — обещание меряет гейт. Убедиться, что существующие
   тесты поверхности не завязаны на одиночную выборку краски.

4. **Веб-стенд** — сцена уже умеет касание; снять кадры «покой / палец» и сверить с эталонными
   кадрами глазами. Правок стенда не планируется; если для нажатия нужен параметр URL —
   добавить его в `apps/web/rnd-src/main.ts`.

5. **Доки**: `docs/vireglass/README.md` (строка про нажатие в таблице/разделе взаимодействия)
   и `docs/features/vireglass-web.md`, если стенд получит параметр.

6. **Гейты локально** (минуты Actions на исходе, один пуш на срез):
   `@vire/vireglass` test + typecheck, `check:glsl`, `check:optics`, `@vire/mobile` test +
   typecheck, `@vire/web` typecheck + lint + build, `pnpm check:doc-paths`.
