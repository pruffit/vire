# План — десктоп-клиент, срез 2 (синк состояния)

Спека: `docs/superpowers/specs/2026-08-16-desktop-shell-slice-2-design.md`.
Продолжает срезы 0-1 (уже в `main`).

**Сужено по ходу:** шаги 3-5 (IPC-команда `report_playback_state`, capabilities,
веб→Rust invoke для синка подписи трея) — ОТЛОЖЕНЫ, не выполнять в этом заходе (см.
пометку в спеке). Выполняются только шаги 1-2 — они не требуют открытия IPC прод-домену
и самодостаточны.

## Шаги

1. **Media Session API в веб-плеере** — найти, где в `apps/web` уже подписываются на
   `usePlayerStore` для сайд-эффектов (искать существующий паттерн, например рядом с тем,
   где уже обновляется `document.title` или похожим client-side эффектом плеера — не
   плодить второе место подписки, если такое уже есть). Добавить туда обновление
   `navigator.mediaSession.playbackState`/`.metadata`, и один раз при инициализации —
   `setActionHandler('play'|'pause'|'previoustrack'|'nexttrack', ...)` на `controls`.
   Гард на `'mediaSession' in navigator` (Safari/старые браузеры могут не поддерживать
   часть API — не должно падать).
2. **Проверить SMTC-интеграцию эмпирически**: `cargo tauri dev` + `pnpm --filter @vire/web
   dev`, играть трек, посмотреть Windows-виджет «Сейчас играет» (win+X media flyout или
   аналог) — появляется ли трек. Нажать физическую медиа-клавишу (или эмулировать через
   `keybd_event`, как в срезе 1) при ОБОИХ путях активными (mediaSession + наш
   global-shortcut) — проверить на дублирование (двойной toggle). Если дублирование
   подтверждено — убрать регистрацию медиа-клавиш из `tauri-plugin-global-shortcut` в
   `main.rs` (оставить плагин только если он больше не даёт того же события — то есть по
   факту, не заранее). Задокументировать наблюдение в отчёте максимально конкретно.
3. **Tauri-команда `report_playback_state`**: `apps/desktop/src-tauri/src/main.rs` (или
   вынести в `commands.rs`, если main.rs разрастётся) — `#[tauri::command]`, managed state
   `Mutex<bool>` для текущего playing-статуса, обработчик обновляет state и
   `MenuItem::set_text` на пункте «play_pause» трея. Понадобится держать `MenuItem`
   (или `Menu`) доступным вне `setup`-замыкания — вынести построение трея/меню в managed
   state или отдельную структуру, чтобы команда могла до него дотянуться через
   `app_handle.state()`.
4. **Capabilities**: включить `withGlobalTauri: true` в `tauri.conf.json` **или** добавить
   `@tauri-apps/api` как зависимость `apps/web` (сравнить оба варианта по факту — какой
   проще для `desktop-bridge.ts`, задокументировать выбор в отчёте, не выбирать
   наугад). Настроить `dangerousRemoteDomainIpcAccess` (или актуальный синтаксис Tauri v2
   для доступа удалённого домена к конкретной команде — свериться с документацией Tauri v2
   по капабилити для remote domains, не полагаться на память) — **ограничить ровно
   командой `report_playback_state` и доменами `https://viremusic.ru`,
   `http://localhost:3000`**. Прочитать итоговый JSON целиком перед тем как считать шаг
   готовым — убедиться, что не открылось ничего лишнего (файловая система, shell, другие
   команды).
5. **Веб-мост** (`apps/web/lib/desktop-bridge.ts`): подписка на `usePlayerStore.isPlaying`,
   на каждое изменение — `invoke('report_playback_state', { playing })` через
   `window.__TAURI__` (или импортированный `@tauri-apps/api/core`, в зависимости от выбора
   шага 4), с гардом на отсутствие Tauri-контекста (браузер не должен ничего звать/падать).

## Проверка

- Реальный play/pause через UI страницы в открытом окне → подпись трея меняется без
  вмешательства в сам трей.
- Клик по трею по-прежнему управляет плеером (регресс среза 1 не допустить).
- `pnpm --filter @vire/web typecheck && lint && test`.
- `cargo tauri build` — новая команда/managed state не ломают сборку.
- В отчёте — дословный итоговый JSON capabilities-разрешения (шаг 4), подтверждение, что
  скоуп не шире одной команды/двух доменов.

## Делегирование

Один сабагент (Sonnet), фон — снова не мгновенно (пересборка Tauri). Самокритика: если
диф по capabilities/IPC получится нетривиальным — держи в уме, что это первое место в
проекте, где прод-домен получает Tauri IPC-доступ; не полагайся только на «скомпилировалось»,
перечитай сам JSON и код обработчика перед отчётом.
