# Поиск (страница, инлайн-дропдаун, ⌘K палитра)

Единый поиск по артистам, релизам и трекам. Три точки входа над одним API.

## Что делает
- **Страница `/search?q=`** — SSR-результаты, сгруппированные по артистам/
  релизам/трекам (`force-dynamic`). Минимум 2 символа.
- **Инлайн-дропдаун** (`GlobalSearch`) — поле с живой выдачей при вводе
  (debounce 200мс), навигация стрелками/Enter, Esc/клик-вне закрывают. Enter без
  выбора → уходит на `/search?q=`. Варианты `hero` и `page`.
- **Командная палитра `⌘K` / `Ctrl+K`** (`CommandPalette`) — модальный оверлей
  «прыжок куда угодно»: быстрые действия (Главная/Артисты/Лента/Профиль/Дашборд)
  + те же результаты поиска (debounce 180мс). Глобальный хоткей вешается на
  `document`.
- **Поиск в навбаре** (`nav-search.tsx`) — раскрывающееся поле в шапке.

## Где код
- **Страница:** `apps/web/app/[locale]/(listener)/search/page.tsx` (+ `search-tracks-section.tsx`,
  `search-releases-section.tsx`)
- **Инлайн-поиск:** `apps/web/components/global-search.tsx`
- **Палитра:** `apps/web/components/command-palette.tsx`
- **Навбар:** `apps/web/components/nav-search.tsx`
- **API:** `apps/web/app/api/v1/search/route.ts` — `GET ?q=` → `searchAll(q, limit)`
- **Данные/логика:** `searchAll` в `@vire/db`, типы `SearchResults` /
  `SearchArtist` (поиск по `display_name`/`title`, фильтр по публичным/активным)

## Env
Не требуется (только `DATABASE_URL`).

## Ограничения / на будущее
- Порог запроса — 2 символа; короче не ищем.
- Поиск подстрочный (ILIKE-стиль), без полнотекстового индекса/ранжирования по
  релевантности и без опечаток/транслита.
- Лимит результатов фиксирован (страница — 20, дропдаун/палитра — меньше).
- Не ищет по постам, плейлистам, текстам/credits.
