# Feature flags

Переключатели фич, живущие в БД: раскатка и откат без деплоя. Заведены как предусловие
волны 8 (SDUI за флагом) — откат должен быть выключением, а не ревертом релиза.

## Что делает

- Набор флагов задаёт **реестр в коде** (`FEATURE_FLAGS`), а не таблица: неизвестный ключ —
  ошибка, а не «выключено». Строка в БД появляется только у перекрытых флагов; пока её нет,
  действует `defaultEnabled` из реестра.
- `/admin/flags` показывает все флаги реестра, их состояние, источник (умолчание/база) и
  время последнего переключения. Тумблер доступен ADMIN/SUPERADMIN; MODERATOR и VIEWER видят
  состояние, но не меняют его.
- Переключение пишется в `audit_log` (`flag.set`), как остальные мутации бэкофиса.
- Чтение флага кэшируется в процессе на 30 секунд: переключение доезжает до всех инстансов
  без рестарта, но БД не читается на каждый рендер.

## Где код

- **Страницы:** `apps/web/app/admin/flags/page.tsx`, `flag-row.tsx` (тумблер на `Switch` из `ui-kit`)
- **Server action:** `actionSetFeatureFlag` в `apps/web/app/admin/actions.ts` (право `admin.flags.manage`)
- **Сервис/реестр:** `packages/core/src/platform/config/feature-flags.ts`
  (`FEATURE_FLAGS`, `FeatureFlagService`, порт `IFeatureFlagRepository`)
- **Фабрика в приложении:** `apps/web/lib/feature-flags.ts` (`isFeatureEnabled(key)`) — один
  инстанс на процесс, иначе TTL-кэш бессмыслен
- **Репозиторий:** `packages/db/src/repositories/feature-flag.ts`
- **Данные:** таблица `feature_flags` (`key` PK, `enabled`, `updated_at`, `updated_by` → `users.id` on delete set null), миграция `0054`

## Env

Не требуется.

## Как добавить флаг

1. Объявить в `FEATURE_FLAGS` (ключ вида `область.фича`, `defaultEnabled`, описание для админки).
2. Читать через `isFeatureEnabled('область.фича')` в нужном месте.
3. Всё — строка в БД создастся при первом переключении в админке.

## Ограничения / на будущее

- Флаг булев и глобальный: ни процента раскатки, ни таргетинга по пользователю — появится,
  когда будет реальный сценарий, а не заранее.
- Кэш процессный (`createTtlCache`), не распределённый: после переключения инстансы
  расходятся максимум на 30 секунд.
- Флаги не проверяются на «использование»: удалённый из реестра ключ оставит осиротевшую
  строку в таблице — она безвредна, но не подчищается автоматически.
- Текущий реестр: `sdui.home` (выключен) — рубильник для волны 8, потребителя пока нет.
