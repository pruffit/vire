# Смартлинки (bandlink-лендинги)

Красивые страницы релиза со ссылками на стриминги и соцсети — самостоятельный
маркетинг-инструмент в стиле Linkfire/feature.fm. **Работают без публикации музыки
на Vire**: артисту нужен только профиль, треки заливать не обязательно.

Публичный URL: `/smartlink/{artistSlug}/{slug}`.

## Что делает
- **Лендинг** — обложка, название, артист, дата + крупные кнопки площадок в теме
  артиста (`theme_tokens`). Площадка распознаётся из URL → своя иконка/название.
  Ссылка ведёт на карточку артиста и обратно (навигация хаб ↔ лендинги).
- **Карточка артиста** = хаб: ссылки артиста показываются иконками площадок,
  секция «Слушать на площадках» со всеми опубликованными смартлинками.
- **Распознавание площадки** — по домену (`detectPlatform`): Spotify, Apple Music,
  YouTube/YT Music, Яндекс Музыка, VK/VK Музыка, Звук, SoundCloud, Bandcamp +
  соцсети (Telegram, Instagram, TikTok, X, сайт). Неизвестное — обычной ссылкой.
- **Дашборд** `/dashboard/links` — CRUD: обложка (S3), название, адрес (slug с
  автогенерацией из названия), подзаголовок, дата, ссылки (автоиконка), публикация.

## Где код
- **Схема:** `packages/db/src/schema/artists.ts` (`smart_links`, миграция `0018`),
  `target` — артист, `slug` уникален в пределах артиста.
- **Тип:** `packages/core/src/types/artist.ts` (`SmartLink`, `ArtistLink.label` → опционально).
- **Запросы:** `packages/db/src/queries/smart-links.ts` (get/list/create/update/delete + slug-проверка).
- **Площадки/иконки:** `apps/web/lib/platforms.ts` (`detectPlatform`, `linkLabel`),
  `apps/web/components/platform-icon.tsx` (оригинальные глифы, не бренд-лого).
- **Валидация:** `apps/web/lib/smart-link.ts` (`normalizeSlug`, `isValidSlug`, `parseSmartLinkLinks`).
- **Публичная страница:** `apps/web/app/smartlink/[artistSlug]/[linkSlug]/page.tsx`.
- **Дашборд:** `apps/web/app/dashboard/links/*` (список, форма, new, [id]).
- **API:** `apps/web/app/api/v1/dashboard/smart-links/route.ts` (POST),
  `.../[id]/route.ts` (PATCH/DELETE).
- **Хаб:** `apps/web/app/artists/[slug]/page.tsx` (иконки ссылок + секция смартлинков).

## Env
- S3 (обложки в публичный `stream`, ключ `covers/smartlinks/{uuid}.{ext}`) — те же
  переменные, что у обложек релизов.

## Ограничения / на будущее
- Иконки — оригинальные упрощённые глифы, не точные бренд-лого (можно заменить позже).
- Площадка определяется при рендере из URL (в БД хранится только url + опц. подпись).
- Slug — только латиница/цифры/дефис; кириллические названия дают slug из того,
  что осталось (артист правит вручную).
- Лендинг наследует тему артиста; отдельной темы у смартлинка пока нет.
- Self-serve онбординг артиста (без админа) — отдельная задача; сейчас профиль
  создаёт админ.
