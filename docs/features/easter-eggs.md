# Пасхалки

Скрытые интерактивные элементы платформы: код Konami и терминал-страница `/fwqa688`
с «загадочным» прогресс-баром.

## Что делает

- **Код Konami** (`↑ ↑ ↓ ↓ ← → ← → B A`, слушает `e.code` — не зависит от раскладки)
  открывает попап-приглашение со ссылкой на `/fwqa688`.
- **`/fwqa688`** — скрытая терминал-страница (не в sitemap, `robots: noindex`): бегущая
  строка, глитчующий морзе-логотип и детерминированный прогресс-бар «готовности
  протокола», который растёт месяцами/годами с лёгким дневным джиттером (иногда
  «откатывается» на пару сотых — ARG-атмосфера) и изредка на ~150мс «глючит» последние
  два знака.

## Где код

- **Компонент:** `apps/web/components/easter-eggs.tsx` — Konami-попап (`SecretPopup`);
  подключён через `apps/web/components/deferred-widgets.tsx`.
- **Триггеры:** `apps/web/components/widget-triggers.tsx` — `OPEN_ANNOUNCEMENT_EVENT`.
- Нотный дождь по тройному клику на копирайт удалён 01.08.2026; сам жест отдан под
  вход на секретную страницу вечеринки (см. `docs/features/party.md`, срез C).
- **Страница:** `apps/web/app/fwqa688/page.tsx` + `layout.tsx` (noindex).
- **Формула прогресса:** `apps/web/lib/black-sky.ts` — `blackSkyProgress(now: Date): number`,
  чистая функция, покрыта тестом `black-sky.test.ts`.

## Формула «чёрного неба»

```
days = (now - EPOCH) / 86400000        // EPOCH = 2026-01-11T00:00:00Z
base  = 100 * (1 - exp(-days / 500))   // ≈6% через месяц, ≈50% через год
jitter = (hash(YYYY-MM-DD) * 2 - 1) * 0.4   // ±0.4%, детерминированный hash даты (UTC)
progress = clamp(base + jitter, 0.1, 99.9), округление до 4 знаков
```

Хеш строки даты — простой (не криптографический), но детерминированный: одна и та же
дата всегда даёт один и тот же джиттер. Никакого `Math.random()` в самой формуле —
только в кратковременном визуальном «глюке» цифр на странице (не влияет на реальное
значение, оно считается один раз на маунте).

## Env

Не требуется.

## Ограничения / на будущее

- Значение прогресса считается один раз при маунте страницы (`useState(() =>
  blackSkyProgress(new Date()))`), не тикает в реальном времени — обновится только
  при следующей загрузке страницы.
- Числовой узел прогресса помечен `suppressHydrationWarning` — SSR/build-момент и
  клиентский маунт математически почти всегда отличаются на доли секунды, что даёт
  разные последние знаки; сам факт различия ожидаем и не является багом.
