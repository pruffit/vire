# Глобальный плеер

## Что делает

Постоянный плеер внизу app-shell. Воспроизводит треки через HLS. Поддерживает очередь, waveform-скруббер, горячие клавиши.

### Архитектура

- Стор: Zustand (`usePlayerStore`) — трек, статус, очередь, громкость, прогресс
- Воспроизведение: `hls.js` — подключается к `<audio>` и загружает `.m3u8`-манифест с S3
- Waveform: SVG-скруббер, данные из `track_audio.waveform_peaks` (JSONB), кликом и drag'ом задаёт seek
- Плеер — элемент потока в app-shell (не фиксированный), высота `h-16`, появляется только когда играет

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Space` | Play / Pause |
| `←` / `→` | -5с / +5с |
| `M` | Mute toggle |
| `F` | Favourite (любимый момент) |
| `↑` / `↓` | Громкость ±10% |

### Очередь

- Добавить трек / релиз / результаты Волны
- Навигация: предыдущий/следующий трек
- Seed-режим (Волна): при исчерпании очереди автоматически запрашивает `/api/v1/wave` и дополняет

### Wave-режим (авто-плей)

При включённом seed-режиме плеер отправляет запрос к Волне когда в очереди ≤1 трека. Параметры seed берутся из текущего трека.

## Где код

- **Стор:** `apps/web/lib/player-store.ts` (Zustand)
- **Компонент плеера:** `apps/web/app/_components/Player.tsx` (или `apps/web/components/player/`)
- **Waveform-скруббер:** `apps/web/app/_components/WaveScrubber.tsx`
- **HLS-хук:** внутри компонента плеера, `new Hls()` → `hls.loadSource(manifestUrl)`
- **Горячие клавиши:** `apps/web/lib/player-hotkeys.ts` или хук `usePlayerHotkeys`
- **Утилиты медиа:** `packages/media/src/hls.ts`

## Env-переменные

```
S3_PUBLIC_ENDPOINT=             # базовый URL для построения ссылок на HLS-манифест
```

## Известные ограничения

- Только HLS — прямые mp3/flac-ссылки не используются
- `hls.js` не поддерживается в Safari ≤ 9 (там используется нативный HLS через `<video>`)
- Waveform-пики вычисляются воркером при транскодинге; если воркер не запущен — пики отсутствуют, скруббер показывает плейсхолдер
- Плеер не сохраняет позицию между перезагрузками страницы
- **Громкость на iOS:** `HTMLMediaElement.volume` там read-only (звук рулят хардварные
  кнопки), поэтому ползунок громкости скрыт. Скрытие — по **фича-детекту**
  (`lib/can-control-volume.ts`: пробуем выставить `volume` и проверяем, применилось ли),
  а НЕ по UA: иначе в iOS-вебвью (Chrome/Yandex/in-app, UA без `iPhone`) ползунок вылезал
  и не работал. Касается всех ползунков — и фуллскрин, и десктоп-бар (iPad ландшафт)
