# Посты артиста (анонсы/новости)

Короткие записи артиста (анонсы, новости) на его профиле. Лента артиста ниже
дискографии: текст + опциональный заголовок, без обложек и вложений.

## Что делает
- Артист пишет пост из дашборда (`/dashboard/posts`): композер, инлайн-
  редактирование, оптимистичное удаление.
- Пост виден всем на публичной странице артиста `/artists/[slug]`.
- Привязан к профилю артиста (`onDelete: cascade` — удаляется вместе с профилем).
- Создаётся под **активным** артистом аккаунта (см. [multi-artist](multi-artist.md)) — пост
  попадает тому профилю, что выбран переключателем.

## Где код
- **Страница (дашборд):** `apps/web/app/dashboard/posts/page.tsx` +
  `posts-manager.tsx` (композер, инлайн-правка, удаление)
- **Показ на профиле:** `apps/web/app/artists/[slug]/page.tsx` (секция анонсов)
- **API:**
  - `apps/web/app/api/v1/dashboard/posts/route.ts` — `POST` (создать)
  - `apps/web/app/api/v1/dashboard/posts/[id]/route.ts` — `PATCH`/`DELETE`
- **Данные:** `artist_posts` (FK `artist_profile_id`, `title` nullable, `body`),
  хелпер `createArtistPost` в `@vire/db`

## Env
Не требуется (только `DATABASE_URL`).

## Ограничения / на будущее
- Лимиты длины: заголовок ≤ 120, тело ≤ 2000 символов (проверка в роуте).
- `body` обязателен, `title` опционален.
- Без вложений (картинок/аудио) и без markdown-форматирования.
- Нет уведомлений подписчикам о новом посте (письма шлются только о релизах —
  см. [mailings](mailings.md)).
