# Загрузка и валидация файлов

Артист загружает аудио-мастера и изображения (обложки, аватары). Вся валидация —
по **реальным байтам заголовка**, не по клиентскому MIME (спуфинг не проходит).

## Что делает

### Аудио (треки)
- Форматы: **WAV, FLAC, MP3** (определяются по расширению + magic bytes).
- **Кодек WAV не ограничиваем.** Принимаем любой валидный RIFF/WAVE — PCM, 32-бит
  float (типичный экспорт DAW), сжатый. Воркер всё равно прогоняет мастер через
  ffmpeg (как MP3/FLAC), а он декодирует всё. Частоту/битность тоже не ограничиваем;
  рекомендация 44.1/16-24 — текстом в форме.
- Лимит размера 300 МБ. Загрузка пачкой (drag-n-drop + мультивыбор) с прогрессом
  и live-статусом обработки (PROCESSING → готов).

### Изображения (обложки, аватары)
- Форматы: **JPEG, PNG, WebP** (VP8/VP8L/VP8X) — `probeImage` читает размеры из заголовка.
- **Обложка:** строго квадрат 1:1, 1400–6000 px, до 15 МБ (рекомендация 3000×3000).
- **Аватар** (артист и слушатель): около-квадрат (≤ 2:1), 400–4000 px, до 5 МБ.

## Где код
- **Валидаторы (чистые функции):**
  - аудио — `apps/web/lib/upload.ts` (`parseAudioExt`, `validateMagicBytes`,
    `sanitizeCredits`)
  - изображения — `apps/web/lib/image.ts` (`probeImage`, `validateImageUpload`,
    `COVER_POLICY`, `AVATAR_POLICY`)
- **API:**
  - трек — `app/api/v1/dashboard/tracks/upload/route.ts`
  - статус треков (поллинг) — `app/api/v1/dashboard/releases/[id]/tracks/route.ts`
  - обложка — `app/api/v1/dashboard/releases/route.ts` и `.../releases/[id]/route.ts`
  - аватар артиста — `app/api/v1/dashboard/profile/route.ts`
  - аватар слушателя — `app/api/v1/user/profile/route.ts`
- **UI:** `app/dashboard/releases/[id]/batch-track-upload.tsx` (пачка),
  `track-manager.tsx` (статусы + редактор кредитов), `components/credits-editor.tsx`
- **Транскодинг:** `apps/worker` (FLAC/WAV/MP3 → HLS, форматно-агностичен через ffmpeg)
- **Хранилище:** мастер в приватный `vault` (`tracks/{id}/source.{ext}`), HLS/обложки/
  аватары — в публичный `stream`.

## Env
- S3: `S3_ENDPOINT`, `S3_PUBLIC_ENDPOINT`, ключи/бакеты (см. `.env.example`).
- Лимит размера тела прокси (Caddy) согласован с 300 МБ.

## Ограничения / на будущее
- Картинки не пережимаются на сервере (нет sharp) — аватар кропится CSS-ом
  (`object-cover`), обложка должна быть квадратной уже на входе.
- Ручная правка BPM/тональности есть в менеджере; авто-анализ при транскоде —
  основной источник.
- Кредиты при пачечной загрузке автозаполняются исполнителем = имя артиста;
  богаче — через редактор кредитов после загрузки.
