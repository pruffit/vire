# Видео-эмбеды (YouTube / VK)

Артист добавляет ссылку на видео (YouTube или VK) на свой профиль. Показывается
лёгким плеером-фасадом: статичный постер до клика, по клику — один iframe с
автоплеем и **родными контролами площадки**.

## Что делает
- Принимает ссылку YouTube (`watch`/`youtu.be`/`shorts`) и VK (`vk.com`,
  `vkvideo.ru`, формат `video{oid}_{id}` в пути или `?z=`).
- **Парсер** превращает ссылку в `{ platform, id, embedUrl, thumbnailUrl }`.
- **Фасад**: пока не нажали play — только постер + кнопка, iframe не грузится
  (быстро, без скриптов/трекеров платформы до клика). При наведении/фокусе —
  `preconnect` к домену площадки, чтобы iframe стартовал быстрее.
- **По клику** монтируется один iframe (`activeEmbedUrl` с `autoplay=1`) с
  нативными контролами YouTube/VK: перемотка, громкость, качество, субтитры,
  фуллскрин, PiP. Самописных контролов поверх iframe нет — поэтому быстрее,
  полный набор функций площадки, а на паузе виден реальный кадр (не постер).
- Один компонент `VideoPlayer` на обе платформы (различие — только в `embedUrl`).

## Где код
- **Парсер:** `apps/web/lib/embed.ts` (`parseEmbed`, `getEmbedUrl`,
  `activeEmbedUrl`) — чистые функции, покрыты `lib/__tests__/embed.test.ts`
- **Плеер:** `apps/web/components/video-player.tsx` (`VideoPlayer` + `Facade`)
- **VK-постер:** подтягивается на сервере (`lib/vk-api.ts` → `fetchVkPoster`) в
  `VideosSection` страницы артиста — у VK его нет в ссылке.
- **Где используется:** профиль артиста `apps/web/app/(listener)/artists/[slug]/page.tsx`;
  ссылка вводится в `dashboard/profile/edit-profile-form.tsx`
- **Данные:** ссылка хранится в профиле артиста (`artist_profiles`)

## Env
Не требуется (iframe грузится с домена площадки на клиенте по клику).

## Ограничения / на будущее
- Только YouTube и VK. Прочие платформы → `parseEmbed` вернёт `null`.
- Контролы и оверлеи — нативные для площадки (не в стиле сайта). Сознательный
  размен на скорость, надёжность и полный набор функций (см. историю: раньше были
  самописные контролы поверх IFrame/Video Player API — медленно и хрупко).
- Если владелец запретил встраивание (YouTube), iframe сам покажет «Смотреть на
  YouTube» — отдельный фолбэк не нужен.
- Видеохосты должны быть разрешены CSP `frame-src` (см. `next.config.ts`).
