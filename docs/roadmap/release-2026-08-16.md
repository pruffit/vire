## Изменения поведения — на что смотреть после выкатки

1. **Процесс не стартует без обязательных env** (`DATABASE_URL`, `REDIS_URL`, `AUTH_SECRET`,
   `S3_ENDPOINT`, `S3_ACCESS_KEY`, `S3_SECRET_KEY`, `S3_BUCKET_VAULT`, `S3_BUCKET_STREAM`).
   Прод-`.env` их содержит (`env_file: .env` отдаёт контейнеру всё). Отсутствие
   необязательных пишет один warn со списком выключенных фич — это ожидаемо.
2. **Новая очередь `storage-cleanup`** в воркере, расписание `30 * * * *`. Первый проход
   удалит файлы только тех треков/релизов, что удалены **после** выкатки (grace 24 ч).
   Осиротевшее до релиза не трогается — записей о нём нет.
3. **`POST /v1/tracks/{id}/purchase`** при отсутствии `confirmationUrl` теперь отдаёт 503
   вместо 200 с пустым полем. Продажи в UI отключены, влияние нулевое.
4. **Очередь транскодинга** принимает новый payload и старый. Джобы, лежащие в Redis на
   момент выкатки, обработаются (проверено тестом и сквозным прогоном).
5. **Bearer-аутентификация доступна на всех `/api/**`**, но токенов ещё никто не выдаёт:
   первый выдаётся только по cookie-сессии через `POST /v1/auth/devices`.
6. **Флаг `sdui.home` выключен.** Главная рендерится прежним JSX. Включение — в `/admin/flags`,
   действует в течение 30 с.

## Порядок выкатки

1. Тег `vX.Y.Z` → CI гоняет `gates` (typecheck, lint, `check:routes`/`i18n`/`contracts`/`caller`,
   layers, тесты, `pnpm audit`, smoke) и собирает образы.
2. Деплой: `pull` → `migrate` (`tsx src/migrate.ts`) → `up -d`.
3. После: проверить `/api/health`, зайти в `/admin/flags` (флаг виден, выключен), убедиться,
   что воркер поднялся без ошибок env.
