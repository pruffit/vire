# Этап 1 — Friends & Family — закрыт ✓

> Часть дорожной карты VireMusic. Обзор всех этапов и продуктовая концепция — [`concept.md`](../vision/concept.md).
> Соседние этапы: [этап 2 — прямые продажи](stage-2.md), [этап 3 — площадка](stage-3.md), [этап 4 — стриминг](stage-4.md).

Личный сайт-витрина, который изнутри устроен как платформа, но запускается как проект для своих. Цель — собрать продукт, обкатать его на себе и друзьях-музыкантах, выстроить эстетику и удобство до того, как появятся деньги и чужие права.

## Что задумывалось

- Артист-профиль по адресу вида `/artists/[slug]` — архитектура сразу заложена под многих, но пока это ты и приглашённые друзья
- Все релизы в одном месте: обложки, трек-листы, год, теги
- Страница релиза: полноэкранная обложка, трек-лист, описание, credits, liner notes
- Собственный аудиоплеер — нижняя панель в духе Spotify, живёт поверх навигации, очередь треков, перемотка, громкость
- Транскодинг с первого дня — артист заливает FLAC, система не просто жмёт его, а **нарезает на чанки и отдаёт по HLS** (`.m3u8` плейлист + сегменты). HTML5 `<audio>` работает с HLS через `hls.js`. Это даёт три вещи сразу: мгновенный старт воспроизведения (не ждёшь загрузки всего файла), ещё меньший egress (качается только то, что реально слушают), и готовую базу под шифрование чанков и офлайн-кэш на этапе 4. Прямую ссылку на цельный mp3 не отдаём — иначе каталог сливается скриптом за полчаса. Сырой FLAC лежит в холодном хранилище под замком и отдаётся только по факту скачивания
- Видео — клипы и влог через embed (YouTube / VK)
- Раздел ссылок на все ресурсы — свой линктри без чужого брендинга
- Тёмный пресет темы (твой личный), зерно/grain как на обложках, плавные переходы. Важно: это тема твоего профиля, а не всего сайта — см. [`concept.md` → «Темизация»](../vision/concept.md#темизация--три-слоя)

### Эстетика (твой пресет)

Тёмный фон, не чистый чёрный, с лёгкой теплотой. Типографика между технологичным и органичным — моноширинный для акцентов, humanist sans для текста. Пыльный беж и выцветший кремовый как цвета, один холодный акцент. Текстура зерна — через оптимизированный SVG-фильтр с аппаратным ускорением (`will-change: transform`), а не тяжёлый анимированный overlay, чтобы не превращать слабые смартфоны в слайд-шоу и не выжигать батарею.

Это эталонный, но **не единственный** вид сайта. Это пресет артиста Kotlaev Danil. Другой артист задаст светлый минимализм или что угодно своё — архитектура темизации это предусматривает с первого дня.

### Юридически

Почти ничего не требуется. Это личный проект, музыка публикуется по прямому согласию участников. Денег нет — нет финансового посредничества, нет налогового агента.

Но один реальный пункт всё же возник: **ФЗ-406** запрещает российским сайтам авторизацию через иностранные сервисы — поэтому вход через Google и Telegram убран, остались email (пароль / magic-link) и Яндекс. Плюс возрастная маркировка контента (**436-ФЗ**) — у треков есть метка explicit (18+).

## Что вышло по факту — этап закрыт ✓

Этап 1 **полностью закрыт** и оказался заметно шире исходной «витрины». Он вобрал почти все слушательские взаимодействия, которые в этой концепции планировались на этап 3, и часть инструментов артиста — потому что они дёшевы и сразу делают продукт живым. Ниже — полный состав того, что работает на проде (всё, что есть на сайте, на странице `/about` и в [`docs/features/`](../features/README.md), считается частью этого этапа).

**Слушатель:**
- Глобальный плеер на всех страницах — очередь, перемотка по форме волны, громкость (десктоп), горячие клавиши (пробел, стрелки, M); звук только потоком (HLS), без скачивания файла
- **Волна** — бесконечный поток: ступень 1 (теги настроения / BPM / тональность / жанр) **плюс ступень 2** (поведенческие сигналы из лога прослушиваний: качество дослушивания, профиль вкуса, анти-усталость, любимые моменты); seed-режим от любого трека, автоплей при исчерпании очереди
- Лайки треков — синхронны в плеере, трек-листе и на странице трека, собираются в профиле
- Плейлисты — приватные / по ссылке, добавление, переименование, удаление; курируемые, алгоритмические (editorial по крону) и пользовательские подборки на главной
- Подписки на артистов и личная лента релизов и анонсов
- Теги настроения треков (mood-picker) + фильтр по жанрам в каталоге и поиске
- Любимые моменты — анонимные маркеры на волне, агрегат на странице трека
- Шеринг с таймкодом — обычная ссылка или «с момента M:SS»
- Live «слушают сейчас» — Redis-присутствие (деградирует до 0 при сбое Redis)
- Синхронизированный текст (LRC) — подсветка строк по таймкодам, перемотка по клику
- Поиск — отдельная страница, инлайн-дропдаун, командная палитра ⌘K / Ctrl+K
- Профиль — свой аватар в S3, способы входа (пароль + привязка провайдеров), лайки/подписки/плейлисты

**Артист:**
- Страница артиста — full-bleed hero, темизация (live color picker, зерно, шрифты, расширенные пресеты), ссылки, видео (YouTube/VK), follow, анонсы
- Дашборд — релизы со статусами, аналитика прослушиваний / уникальных слушателей / переслушиваний, динамика по дням, live-счётчик в шапке
- Загрузка релизов — FLAC → S3 → HLS-транскодинг + форма волны; статусы DRAFT / SCHEDULED / PUBLISHED, публикация по расписанию с обратным отсчётом и авто-рассылкой
- Карточка трека — BPM и тональность (автоанализ при транскоде), explicit (18+), liner notes, credits, доли соавторов (`track_contributors`)
- Текст трека — редактор LRC / обычного текста
- Посты-анонсы — композер + инлайн-редактирование + оптимистичное удаление
- **Смартлинки** (bandlink-лендинги) — фаза A + B (привязка к релизу VireMusic), хаб на странице артиста
- **Пресейвы** релизов — нативный пресейв на экране отсчёта, авто-выход SCHEDULED по дате, авто-лайк + письмо

**Платформа:**
- Backoffice / админка (`/admin`) — модерация, health (Postgres/Redis/BullMQ), аналитика, управление пользователями / артистами / треками / релизами, верификация
- SEO — metadataBase, OG/Twitter, canonical, Schema.org JSON-LD, robots / sitemap / manifest
- Доступность (a11y) — skip-link, focus-visible, prefers-reduced-motion, cursor-pointer
- Согласия — cookie-баннер, уведомления; страницы `/terms`, `/privacy`, `/feedback`
- Темизация на уровне данных — `theme_tokens` в профиле артиста
- Auth.js v5 — email (пароль / magic-link) + Яндекс; Google и Telegram убраны по 406-ФЗ; письма через Brevo HTTP API
- Инженерная зрелость — CI/CD по тегу `vX.Y.Z`, бэкапы Postgres + vault, rate limiting, security headers / CSP, мониторинг (health + Telegram-алерты)

**Продажи (этап 2) — бэкенд готов, но выключен:** API покупки / скачивания / вебхука написаны, UI отвязан от витрины до старта [этапа 2](stage-2.md).
