## Справка

**Обратный отсчёт до релиза.** Артист создаёт релиз с будущей датой и жмёт
«Запланировать» → SCHEDULED. Публичные запросы показывают SCHEDULED только когда
`release_date <= now()` — релиз открывается сам, без крона. До этого висит
`CountdownBadge`. При публикации уходит рассылка подписчикам
(queue notify-release → **Brevo HTTP API**, `apps/worker`).

**Авто-теги треков.** BPM и тональность — автоанализ аудио при транскоде
(+ бэкфил в админке); mood — ставит артист; жанр — ставит артист (69 жанров,
сгруппированы). Полноценный ML-автотег жанра/настроения — за рамками 1.0.
